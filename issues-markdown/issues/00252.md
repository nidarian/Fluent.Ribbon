## batzen commented on 2016-01-21T20:10:45Z

I found out why this happens.
The Fluent:StatusBar contains a custom StatusBarPanel which automatically sorts children and collapses everything which has a HorizontalAlignment != left or right.

I don't completely know why this was done in 2010 as i was not part of this project at that point in time.
But from my findings i can tell that the custom StatusBarPanel automatically collapses items based on the already used width of all items. Thus taking that burden from everyone using it.

I my opinion the whole statusbar story (styles, templates, classes) could need some refactoring, but as i never had problems with it, it's not very high on my priority list.

If you absolutely need HorizontalAlignment=stretch you can still use a regular StatusBar, although you would loose the contextmenu etc..
