I would like to disable automatic key tips (1,2,3,...) for the quick access toolbar since my application uses these key tips for other buttons.
I know I can customize the quick access key tips with the `KeyTip` property, but I cannot remove them this way:
- `KeyTip = ""` causes a crash
- `KeyTip = "{x:Null}"` does nothing

Anyway, I would prefer to disable automatic key tip assignment for the whole quick access toolbar, which would also include new items added by the user.

Thank you very much!

- Fluent.Ribbon v6.1.0.326
