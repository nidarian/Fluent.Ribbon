## nishy2000 commented on 2021-11-14T11:51:25Z

@batzen 
I am sorry for the late reply. I've been busy for a while.
I have reviewed your changes.
Display option button is a good idea for If CanUseMinimize and CanUserSiplified are both True.
If only one of them is True, the user operation becomes more complicated.
Also, the UI specification of the existing MinimizeToggleButton will be changed. This means that when an app that uses this library updates this library, the GUI specification will change.
I think that many apps, including Microsoft Office apps, will use only one of the modes.
Therefore, when an app uses only one of the modes (CanUseMinimize and CanUserSiplified), I think the toggle button as before is better.

By the way, I got the localization strings for the Simple Ribbon mode from the [Microsoft language portal](https://www.microsoft.com/en-us/language) site.
This is useful because it is the same localization string used in Microsoft Office, Windows OS and etc.
