## MattMoszczynski commented on 2021-06-26T16:56:23Z

I did manage to make it work with a custom made Converter. This is how it looks when binding in my XAML file:

```
<Fluent:TextBox Header="Price" IsReadOnly="True">
    <Fluent:TextBox.Resources>
        <SolidColorBrush x:Key="Fluent.Ribbon.Brushes.TextBox.Background" Color="{Binding IsPriceCorrect, Converter={StaticResource priceCheckConverter}}"/>
    </Fluent:TextBox.Resources>
</Fluent:TextBox>
```
