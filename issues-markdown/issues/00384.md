## pekspro commented on 2016-12-26T20:16:35Z

WPF and UWP and two totally different frameworks. WPF is targeting desktops and UWP is targeting desktop, tablets, mobile, Xbox, HoloLens etc. There are absolutely some similarities but also a lot of differences. It's no easy task to port Fluent Ribbon to UWP.

Office, Excel and PowerPoint is available in UWP. It looks a bit different compared with the classic version (especially the ribbon bar).

When it comes to Windows Store, it does support classic desktop applications, including WPF. I'm not sure if this is open for every developer yet but some applications could be downloaded right now (like Evernote).
