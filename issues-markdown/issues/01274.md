## batzen commented on 2026-04-14T17:43:26Z

It's kind of expected behavior as there is not much i can do about it.
The issue here is that the window behaviors (custom chrome + glow windows) are attached to the window when the window gets initialized (`OnSourceInitialized`).
`WindowChromeBehavior` gets attached first and has to force a redraw of the window as soon as the custom chrome is applied.
That forced redraw call causes the loaded event to be fired.
You close the window when handling the event.
When the `GlowWindowBehavior` is being attached the window already got marked as disposed, without any way to check from the "outside" as there is no public API for that.

The solution to your problem is quite easy.
Just replace your call `this.Close();` with `this.Dispatcher.BeginInvoke(new Action(this.Close));`.
