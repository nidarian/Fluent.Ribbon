I've noticed that the pop-up for Fluent :DropDownButton appears to be right-aligned instead of left-aligned on Windows 10 and Windows 11. This causes the popup to extend to the left when its width is greater than the button's width, which looks misaligned and inconsistent with typical dropdown behavior.

It seems like the popup flow direction or alignment behavior has changed in recent Windows versions, possibly due to underlying system UI or DPI-related adjustments.

Is this a known issue or a design change in Fluent.Ribbon?
Is there a recommended way to ensure the popup always aligns left (starts from the left edge of the button) regardless of its width or OS version — preferably without overriding the default control template?
