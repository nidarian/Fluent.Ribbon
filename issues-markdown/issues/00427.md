Hi,

Some things done in the video are awfully wrong.
Implementing InitializeComponent by hand and just throwing an exception causes many issues later. The compiler issue should have been fixed by fixing the class name used in the xaml part of the window (`x:Class`).

## CADbloke commented on 2017-06-09T02:48:48Z

I had the same issue in VS2015 designer with the Showcase project. I unloaded the .net 4.0 projects, deleted all the bin and obj folders in my suburb and ... you know the usual WPF routine. It eventually came good but I could only see the first tab

I also found [this SO answer](https://stackoverflow.com/a/4371164/492) to change which `Fluent:RibbonTabItem` you are viewing in the designer, namely this code...

````
<Fluent:Ribbon x:Name="ribbon"  SelectedTabIndex="1">
````
or whatever `SelectedTabIndex` you want to see. Don't forget to comment it out when you're releasing. 

Another designer workaround - I opened it in VS Blend - loaded fine.

I'm sure the "W" in WPF stands for "Weird".
