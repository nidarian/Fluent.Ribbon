## ncksol commented on 2018-02-18T15:21:15Z

I have copied FluentDefaultSystemMenuItemStyle from source code and added extra margin around textblock that is placed into the Header Template like this:
` 

    <Style x:Key="FluentDefaultSystemMenuItemStyle" TargetType="{x:Type MenuItem}">
    <Setter Property="ScrollViewer.VerticalScrollBarVisibility" Value="Auto" />
    <Setter Property="ScrollViewer.HorizontalScrollBarVisibility" Value="Hidden" />
    <Setter Property="Background" Value="{DynamicResource Fluent.Ribbon.Brushes.MenuItem.Background}" />
    <Setter Property="Foreground" Value="{DynamicResource {x:Static themes:ResourceKeys.MainTextGreyBrush}}" />
    <Setter Property="Template" Value="{DynamicResource MenuItemTemplate}" />
    <Setter Property="HeaderTemplate">
      <Setter.Value>
        <DataTemplate>
          <TextBlock Text="{Binding}" Margin="0 4" />
        </DataTemplate>
      </Setter.Value>
    </Setter>
    <Style.Triggers>
      <MultiTrigger>
        <MultiTrigger.Conditions>
          <Condition Property="fluent:MenuItem.IsSplited"
                               Value="True" />
          <Condition Property="HasItems"
                               Value="True" />
        </MultiTrigger.Conditions>
        <Setter Property="Template"
                        Value="{DynamicResource SplitedMenuItemTemplate}" />
      </MultiTrigger>
      <MultiTrigger>

      </MultiTrigger>
      <DataTrigger Binding="{Binding Description, RelativeSource={RelativeSource Self}, Converter={x:Static fluent:IsNullConverter.Instance}}"

## ncksol commented on 2018-02-18T18:13:06Z

So I have found that if I add the following to my RD the style is applied correctly:
`<Style TargetType="{x:Type fluent:MenuItem}" BasedOn="{StaticResource FluentDefaultSystemMenuItemStyle}" />`

But I've also noticed that if I have a ContentTemplate for MenuItem in that same RD, then the style is not applied to those MenuItems which Template I have overridden. Most peculiar.

## ncksol commented on 2018-02-20T16:14:01Z

I have the ControlTemplate named "MenuItemTemplate" in my custom ResourceDictionary. 
Weird thing is - after I went back to the code a day later it works.
All I needed to add is add the style FluentDefaultSystemMenuItemStyle to my RD and set Height. I also needed to put 
`<Style TargetType="{x:Type fluent:MenuItem}" BasedOn="{StaticResource FluentDefaultSystemMenuItemStyle}" />`

in the same RD.
