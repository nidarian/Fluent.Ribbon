We should treat all themes equally by generating their Generic.xaml in the specific theme folder.

That way Themes/Generic.xaml only contains a forward for the default theme.

This means that we have to move the current Generic.txt and Generic.xaml down to Office2010/Generic.txt and Office2010/Generic.xaml.
