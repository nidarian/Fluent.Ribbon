## batzen commented on 2015-10-23T17:00:37Z

You should read the exceptions the debugger throws:
{"Could not load file or assembly 'Microsoft.Windows.Shell, Version=3.5.41019.1, Culture=neutral, PublicKeyToken=31bf3856ad364e35' or one of its dependencies. The system cannot find the file specified.":"Microsoft.Windows.Shell, Version=3.5.41019.1, Culture=neutral, PublicKeyToken=31bf3856ad364e35"}

You can't just add a reference to the Fluent.dll and ignore it's dependencies.
If you are using the .NET 4.0 version you also have to reference/include Microsoft.Windows.Shell.dll and System.Windows.Interactivity.dll.
If you are using the .NET 4.5 version you also have to reference/include System.Windows.Interactivity.dll.
