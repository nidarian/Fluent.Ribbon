## znakeeye commented on 2019-08-16T08:54:59Z

I believe the icon alignment was changed in b4fd7d7ba193315ebb98a903c782e56c7c1df8ca. Not sure about the tab item width though.

I believe this is a styling bug. The `Margin` and `VerticalAlignment` should come from the style, and not be hard-coded in the `ControlTemplate`. Would you agree?

I.e. The following...

```xaml
Margin="4,2,0,0"
VerticalAlignment="Top"
```

Should be:
```xaml
Margin="{TemplateBinding Margin}"
VerticalAlignment="{TemplateBinding VerticalAlignment}"
```

Then you can set those constants on the `RibbonWindowStyle` style instead.
