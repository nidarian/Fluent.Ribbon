## batzen commented on 2017-04-08T08:01:59Z

This issue is two sided. I can lessen the negative effects a bit, but it's mainly caused by your code.

Problem:
You set the bindings for your `IsSelected...Tab` to `OneWay` which will never completely work out using the ribbon because your code is not the only party having to change `IsSelected` on `RibbonTabItem`. You have to use `TwoWay` to allow the `Ribbon` to also change those properties. Otherwise the binding breaks as soon as your code and the ribbon disagree on the current value of the property.
