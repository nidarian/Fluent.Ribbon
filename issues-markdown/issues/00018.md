To duplicate the problem, in the TestWindow.xaml, replace the following code and run the test project:

<pre><code>&lt;FluentTest:TestContent x:Name=&quot;TestContent&quot; /&gt;
</code></pre>With:<pre><code>&lt;DataTemplate DataType=&quot;{x:Type viewModels:MainViewModel}&quot;&gt;
    &lt;FluentTest:TestContent /&gt;
&lt;/DataTemplate&gt;
&lt;/Window.Resources&gt;
&lt;viewModels:MainViewModel&gt;&lt;/viewModels:MainViewModel&gt;
</code></pre>
