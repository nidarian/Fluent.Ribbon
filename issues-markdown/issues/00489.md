## sborkman commented on 2017-12-13T14:41:03Z

Well, that didn't work. After some more investigation, I figured out that the crash actually happens when the program starts up (contrary to what my users were reporting). I tried shutting down the dispatcher on program shutdown, but that didn't prevent the problem. Ultimately, this is what I think I'll do:

In the DestroyAdorner function in Backstage.cs, ignore errors when the program is shutting down:

                try
                {
                    layer?.Remove(this.adorner);
                } catch
                {
                    if (!Application.Current.Dispatcher.HasShutdownStarted)
                    {
                        throw;
                    }
                }

And I will call this when the program begins to shut down (which will run before the code shown above):

Application.Current.Dispatcher.InvokeShutdown();

It's not pretty, but it should work. I don't care if there is an error dismantling the UI when I'm shutting down the program. It would be nice to have the underlying problem fixed, of course.
