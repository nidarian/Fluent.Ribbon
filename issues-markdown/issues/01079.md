## batzen commented on 2022-11-12T16:53:43Z

Only OS versions that are still supported by Microsoft are supported by ControlzEx and Fluent.Ribbon, i think the same goes for MahApps.Metro.
So currently that would be Windows 8.1, Windows 10 and Windows 11.

Could you try to set WindowStyle=None?
The default was changed from None to SingleBorderWindow, which might cause issues on older OS versions.
