## maurosampietro commented on 2016-06-23T15:36:15Z

Using Fluent.GalleryItem is not enough cause MenuItem seems to swallow the click event. It can be solved with a behavior like this:

```
   public sealed class BubbleClickEvent : Behavior<UIElement>
    {
        protected override void OnAttached()
        {
            base.OnAttached();
            AssociatedObject.PreviewMouseDown += AssociatedObject_PreviewMouseDown;
        }

        private void AssociatedObject_PreviewMouseDown( object sender, MouseButtonEventArgs e )
        {
            e.Handled = true;
            var e2 = new MouseButtonEventArgs( e.MouseDevice, e.Timestamp, e.ChangedButton );
            e2.RoutedEvent = UIElement.MouseDownEvent;
            AssociatedObject.RaiseEvent( e2 );
        }

        protected override void OnDetaching()
        {
            AssociatedObject.PreviewMouseDown -= AssociatedObject_PreviewMouseDown;
            base.OnDetaching();
        }
    }
```

use it like this:

add namespace
xmlns:i="http://schemas.microsoft.com/expression/2010/interactivity"

```
<Fluent:InRibbonGallery Header="Number"
                        Icon="{xxx}"
                        ItemsSource="NumberList"
                        IsCollapsed="True">
    <Fluent:InRibbonGallery.ItemTemplate>
        <DataTemplate>
             <Fluent:GalleryItem>
                   <i:Interaction.Behaviors>
                           <viewModels:BubbleClickEvent/>
                   </i:Interaction.Behaviors>
                  <MenuItem Header="{Binding Path=NumberName}" Icon="{Binding Path=NumberImage}"/>
          </Fluent:GalleryItem>
        </DataTemplate>
    </Fluent:InRibbonGallery.ItemTemplate>
</Fluent:InRibbonGallery>

```
