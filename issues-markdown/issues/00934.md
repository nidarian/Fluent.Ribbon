This Implement resolves #933 (support MediumIcon property of RibbonGroupBox).
And this fixes #935.

You can check the behavior in the Spinner RibbonGroupBox of the Fluent.Ribbon.Showcase app.
When the window size is reduced, the Spinner RibbonGroupBox shows the medium size icon as icon of Collapsed State.
```
<Fluent:RibbonGroupBox x:Name="B"
                       Header="Spinners"
                       KeyTip="ZXB"
                       Icon="{DynamicResource Fluent.Ribbon.Images.DefaultPlaceholder}"
                       MediumIcon="{DynamicResource Fluent.Ribbon.Images.DefaultPlaceholder}"
                       IsLauncherVisible="True"
                       LauncherClick="OnLauncherButtonClick">
```

My proposed solution would be:
- Add a new `IconSize` property to `RibbonGroupBox`

Hi @batzen,
Thank you for considering my PR.
I think the idea of the IconSize property is good. When IsSimplified is false (when in full mode), I also think  the default size should be 32x32 except for a few.
 The exception is RibbonGroupBox. The icon of RibbonGroupBox is used when its State is Collapsed. In this case, the icon frame will be displayed, so the default size of 32x32 may be too large, isn't it?
 Before creating this PR, I tried to display a 32x32 icon instead of a 16x16 icon for the RibbonGroupBox, but I found  an icon to be too large.
Therefore, I checked the behavior of the Microsoft Office ribbon and found that this case used the 24x24 equivalent instead of 32x32. Therefore, I created a PR to add this MideumIcon property.
