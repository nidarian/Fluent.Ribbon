When a selected TabItem changes its visibility to collapsed, the default behavior is to select the first visible TabItem.

This behavior is ok if nothing is binding to IsSelected.
If IsSelected is bound we should do nothing: it's binding business.

I suggest this fix on file 'RibbonTabItem', row 473:

replace this   

`item.TabControlParent.SelectedItem = item.TabControlParent.GetFirstVisibleItem();`

with this

```
var isSelectedIsBound = BindingOperations.GetBindingExpression( d, IsSelectedProperty ) != null;
if( !isSelectedIsBound )
    item.TabControlParent.SelectedItem = item.TabControlParent.GetFirstVisibleItem();
```

Thank you.
