## batzen commented on 2020-11-29T06:46:36Z

That's because MONITORINFO was converted from a class to a struct in ControlzEx to fix issues with .NET 5.
I have yet to release an updated version of Fluent.Ribbon compiled against ControlzEx 4.4.
You can either wait for that updated version (which i will release later today) or downgrade to an earlier version of ControlzEx.

Sorry for the issues this has caused, i don't know why we didn't notice that it's a breaking change.
