# Issue #555: RibbonWindow not fully maximized with high DPI

- **State:** closed
- **Author:** vojan
- **Created:** 2018-04-04T09:03:11Z
- **Closed:** 2018-04-07T17:14:30Z
- **Labels:** -
- **Original:** https://github.com/fluentribbon/Fluent.Ribbon/issues/555

Set the screen to High DPI (f.e. 150% or more). Start the Ribbon ShowCase .NET 4.5 with WindowState: Maximized

A black Border is visible and Maximized size is about 5 pixels short on all sides.

Restore window size and go back to Maximized state: Border is OK.

Pinpointed down to one private member function (InitializeWindowChromeBehavior) in RibbonWindow.cs, then the problem does not occur.

---
### Environment

- Fluent.Ribbon __v5.0.2__
- Windows __7__
- .NET Framework __4.6.01055
