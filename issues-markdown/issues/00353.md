## batzen commented on 2016-10-01T08:57:10Z

In 4.0 i made VirtualizingStackPanel the default ItemsPanel for ComboBox.
This has been reverted as it's also not the case for the default ComboBox in WPF.
If you want virtualization to work you have to use 

```
<Fluent:ComboBox.ItemsPanel>
    <ItemsPanelTemplate>
        <VirtualizingStackPanel />
    </ItemsPanelTemplate>
</Fluent:ComboBox.ItemsPanel>
```

Either in your Style or on a per instance level.
Will add a change notice to the changelog for this.
