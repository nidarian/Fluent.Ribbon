<li>Added <code>AbsolutePath.Name</code> and <code>NameWithoutExtension</code> properties</li>
<li>Added <code>AbsolutePath.Exists</code>, <code>FileExists</code>, and <code>DirectoryExists</code> extension methods</li>
<li>Added <code>Project.HasPackageReference</code> and <code>GetPackageReferenceVersion</code></li>
<li>Added <code>UpdateFile</code> variants in <code>SerializationTasks</code></li>
<li>Added <code>StdToText</code> and <code>StdToJson</code> extension methods for <code>IEnumerable&lt;Output&gt;</code></li>
<li>Added newest worker images for Azure Pipelines, GitHub Actions, and AppVeyor generation</li>
<li>Added Azure Pipelines generation for pull-request triggers, fetch depth, and clean checkout</li>
<li>Added Space Automation support for secrets</li>
<li>Added TeamCity support for GUID tokens</li>
<li>Added <code>AzurePipelinesCachePaths</code> for common cache paths</li>
<li>Added <code>AzurePipelines.PhaseName</code> property</li>
<li>Added <code>GitHub.CreateComment</code> for issue and pull-request comments</li>
<li>Added <code>TeamCity.AuthUserId</code> and <code>AuthPassword</code> properties</li>
<li>Added <code>AppVeyorSecretAttribute</code> for generation of secret value entries</li>
<li>Added <code>HttpClient</code>, <code>HttpRequest</code>, and <code>HttpResponse</code> extensions</li>
<li>Added <code>XNode</code> extensions</li>
<li>Added <code>LatestMavenVersionAttribute</code></li>
<li>Added <code>MauiCheckTasks</code></li>
<li>Added <code>MinVerTasks</code> and <code>MinVerAttribute</code></li>
<li>Added <code>PowerShellTasks</code></li>
<li>Added <code>BootsTasks</code></li>
<li>Added <code>NetlifyTasks</code></li>
<li>Fixed check for executables compiled with <code>PublishSingleFile</code></li>

<li>Fixed missing assertion for successful status code in <code>HttpTasks</code></li>
<li>Fixed Azure Pipelines caching</li>
