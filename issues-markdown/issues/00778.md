## batzen commented on 2020-03-24T21:08:14Z

Finally had time to have a look at your code.
The issue is that you are creating buttons as child elements for a menu item.
This causes your button to be rendered inside a menu item as the default item container for children of a menu item is `MenuItem`.
If you change your code to create a `MenuItem` instead of `GISRibbonButton` it will work without the line.
If you want those menu items to be as large as your button is you should be able to set a custom style for those menu items.
