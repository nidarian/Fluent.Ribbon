# Issue #632: Ribbon sometimes clips over other applications

- **State:** closed
- **Author:** niratch
- **Created:** 2018-09-13T21:51:18Z
- **Closed:** 2018-09-19T18:45:18Z
- **Labels:** Bug :lady_beetle:
- **Original:** https://github.com/fluentribbon/Fluent.Ribbon/issues/632

You can sometimes get into a state where the ribbon control is detached from the original window, and yet still visible even though you've switched to another application. To repro:

* Make sure the ribbon is unpinned
* Single-click on a tab to make the ribbon visible for a bit
* Place your mouse over a control in the ribbon tab such as a button
* Alt+Tab to another application

Observe that the ribbon control is still visible and hovering over whatever application you switched to.

- Fluent.Ribbon __v6.1.0.326__
