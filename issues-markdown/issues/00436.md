## batzen commented on 2017-05-17T19:58:21Z

The is no way to do this out of the box by changing one property, if that's what you mean.
You can do the following:
1. Search the visual tree of the ribbon for a control named "TabsGrid"
2. From there search for the first control of type "RibbonScrollViewer"
3. Change it's horizontal alignment to "Right"

## batzen commented on 2017-06-07T18:00:08Z

1. The `Ribbon` has an event `SelectedTabChanged` which you can subscribe to.
2. The `Ribbon` is organized in Tabs so you don't have to do anything special to display content in it other than add groups to tabs and controls to groups. The showcase application contains lots of samples for that.
