<p><em>Sourced from <a href="https://github.com/nuke-build/nuke/releases">Nuke.Common's releases</a>.</em></p>
<blockquote>
<h2>7.0.4</h2>
<ul>
<li>Fixed check on nullable parameter type</li>
<li>Fixed telemetry check on home repository</li>
<li>Fixed missing environment variables for AppVeyor</li>
<li>Fixed <code>ICreateGitHubRelease</code> to work with existing releases</li>

<li>Fixed <code>UnityRunTestsSettings</code> base type</li>
</ul>
<h2>7.0.3</h2>
<ul>
<li>Fixed enumeration value sets to exclude non-public fields</li>
<li>Fixed check for <code>NUKE_ENTERPRISE_TOKEN</code> in <code>build.sh</code> bootstrapping script</li>
<li>Fixed default warnings with suppression</li>
<li>Fixed telemetry to treat types as <em>common</em> when their assembly points to home repository</li>
<li>Fixed filtering of secrets in CLT <code>Output</code> collection</li>
<li>Fixed handling of <code>AbsolutePath</code> collections in <code>ArgumentStringHandler</code></li>
<li>Fixed handling of <code>IAbsolutePathHolder</code> in <code>ArgumentStringHandler</code></li>
<li>Fixed handling of <code>relativePath</code> for <code>SolutionAttribute</code> in <code>StronglyTypedSolutionGenerator</code></li>
<li>Fixed error reporting in <code>StronglyTypedSolutionGenerator</code></li>
<li>Fixed TeamCity <code>pom.xml</code> template to use HTTPS</li>
<li>Fixed duplicated payload serialization in <code>TeamsTasks</code></li>
<li>Fixed missing arguments in <code>OctopusTasks</code></li>
<li>Fixed missing command in <code>UnityTasks</code></li>
<li>Fixed missing members in <code>UnitBuildTarget</code></li>
<li>Fixed argument formatting in <code>MSpecTasks</code></li>
<li>Fixed assertion in <code>UnityTasks</code></li>
</ul>
