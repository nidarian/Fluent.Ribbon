## batzen commented on 2015-08-14T14:10:40Z

That's because the RibbonTabControl is no double TabControl and already has a selected content. The selected content is the RibbonTabItem itself.

So to answer your question on how to change the main content when ribbontab is selected: 
You will have to do that by yourself.

In every app, I found so far, using a Ribbon works the other way around. There you got content and as the content changes the Ribbon changes things like Contextual groups etc..

Does that answer your question?
