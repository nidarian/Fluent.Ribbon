## batzen commented on 2017-04-12T20:02:37Z

You currently have to overwrite the resource `RibbonBackgoundBrush`.

Please note that this resource will be renamed to `Fluent.Ribbon.Brushes.Ribbon.Background` in version 6.0 and that there will be no need to overwrite it starting from version 6.0 as you can just use the code you already tried to use.
