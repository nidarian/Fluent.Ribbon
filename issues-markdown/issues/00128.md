Hi,

Thanks for the great library guys. I'm having a weird issue trying to bind Ribbon Tab Item to contextual tab groups. I'm trying to use some of the example code from fluent test to get it working but nothing seems to be doing it.

XAML Markup (Cutdown): 

``` xaml
<Fluent:Ribbon Name="ribbon_MainRibbon" AutomaticStateManagement="True">
                    <Fluent:Ribbon.ContextualGroups>                        
                      <Fluent:RibbonContextualTabGroup Name="tabGroup1"
                                                 BorderBrush="Magenta"
                                                 Background="Magenta"
                                                 Foreground="Purple"
                                                 Header="Test"                                                         
                                                 Visibility="Visible" />
 </Fluent:Ribbon.ContextualGroups>

<Fluent:RibbonTabItem Name="test02" Group="{Binding ElementName=tabGroup1, Mode=OneWay}" Header="Test" Visibility="Visible" />

</Fluent:Ribbon>
```

Binding Error in VS2013 Output:

System.Windows.Data Error: 4 : Cannot find source for binding with reference 'ElementName=tabGroup1'. BindingExpression:(no path); DataItem=null; target element is 'RibbonTabItem' (Name='test02'); target property is 'Group' (type 'RibbonContextualTabGroup')

## morganenglish commented on 2016-05-02T23:51:47Z

Embarrassingly, the issue was because I had set the data-context of the ribbon to my view model, and the XAML markup was looking for the group binding within the view model instead of directly in the XAML. 

I solved it by creating a RibbonContextualTabGroup property in my view model and referencing them that way.
