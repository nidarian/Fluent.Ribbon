# Issue #434: RibbonGroupBox VisibilityProperty wrong Metadata

Hey its a really short one. 

inside Fluent.Ribbon/RibbonGroupBox on line 600:
VisibilityProperty.AddOwner(typeof(RibbonGroupBox), new PropertyMetadata(OnVisibilityChanged));

as this overrides the Metadata of the VisibilityProperty, this can cause problems, when the PropertyMetadata is also overridden on visual Childs, like Grids with **FrameworkPropertyMetadata** before.

"Metadata override and base metadata must be of the same type or derived type."

Thats why you should change such things to: 
VisibilityProperty.AddOwner(typeof(RibbonGroupBox), new **FrameworkPropertyMetadata(OnVisibilityChanged)**);

I have created a small sample, have a look on CustomControl1.
[WpfApplication1.zip](https://github.com/fluentribbon/Fluent.Ribbon/files/992963/WpfApplication1.zip)


I suggest you to also change this on similar cases
