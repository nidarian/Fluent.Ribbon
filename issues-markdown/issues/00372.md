I defined a default style for my application:

```
<Style TargetType="{x:Type TextBlock}">
  <Setter Property="Foreground" Value="Gray" />
</Style>
```

Now, all BackstageTabItem Header get the same foreground.

Is that a bug or is there a simple way to use the Foreground of the loaded theme?

## batzen commented on 2016-11-16T17:50:04Z

That's not a bug, that's just what happens if you override the default style for a very basic control used everywhere.

>  is there a simple way to use the Foreground of the loaded theme?

Which theme? Your windows theme? The ribbon theme?
The foreground should match the ribbon theme by default.
