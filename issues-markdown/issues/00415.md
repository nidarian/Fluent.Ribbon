# Issue #415: DataContext not forwarded from Ribbon to Backstage (in adorner) and TitleBar

DataContext not forwarded from Ribbon to Backstage (in adorner) and TitleBar.
This causes binding-issues if the datacontext for the window is not the same as the datacontext for the ribbon.

To fix this, DataContext from Ribbon has to be forwarded to the Backstage and it's adorner and the TitleBar.
