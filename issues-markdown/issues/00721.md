### Details

I noticed that the ribbon theme reverts to default light whenever I A) unplug or plug in my laptop to charge or B) set an environment variable (User). My best guess is that the theme resets whenever the WM_SETTINGCHANGE message is broadcasted.

- Fluent.Ribbon 7.0.0-alpha0624
- Windows 10 b. 17763.503
- .NET Framework 4.6.1
