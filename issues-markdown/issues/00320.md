## batzen commented on 2016-11-16T18:01:01Z

> I don't have a problem using ToggleButtons, it would just be nice because I had to bind the logic of radiobuttons into the UI to account for only one ToggleButton being pressed at a given time.

You just have to set `GroupName` on your ToggleButton, which ensures that only one button has it's `IsChecked` set to true.
The showcase application contains a sample for this in "Tests => ToggleButton".
