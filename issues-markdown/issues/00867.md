## batzen commented on 2020-11-10T18:19:38Z

@drakedoglife If you want to use one of the colorful themes you have to use something like `Dark.Blue.Colorful.xaml` or `Light.Blue.Colorful.xaml`.
`Dark.Blue.xaml` the "blue" part here only defines the accent color which affects the backstage, statusbar etc..
