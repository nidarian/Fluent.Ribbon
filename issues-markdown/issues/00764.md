There is a NullReferenceException in 7.0.1 when the ribbon window is not located in the main assembly, but in a resource library dll.

Relevant part of the stack trace:
   at Fluent.RibbonProperties.GetLastVisibleWidth(DependencyObject element)
   at Fluent.RibbonWindow.OnSizeChanged(Object sender, SizeChangedEventArgs e)
   at System.Windows.SizeChangedEventArgs.InvokeEventHandler(Delegate genericHandler, Object genericTarget)

First I thought it is because the iconImage is not there, but indeed this.WindowCommands.ItemsControl is null. Then RibbonProperties.GetLastVisibleWidth throws an exception because element is null. 
 
I will attach a sample project for testing.

### Environment

- Fluent.Ribbon __v7.0.1__
- Windows __10__
- .NET Framework __4.7.2__
