## andersforsgren commented on 2022-03-14T10:46:54Z

Should use a proper template etc. but this is a proof of concept that it works without issues:

```
  public class QuickAccessToolBarSeparator : Separator, IQuickAccessItemProvider
   {
      public QuickAccessToolBarSeparator()
      {
         Width = 16;
         Height = 8;
         LayoutTransform = new RotateTransform(90);
      }

      public bool CanAddToQuickAccessToolBar
      {
         get { return true; }
         set {  }
      }

      public FrameworkElement CreateQuickAccessItem() => this;
   }
```
