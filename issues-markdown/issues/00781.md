Hi!
Instead of using App.xaml's StartupUri, I want to create the RibbonWindow in the OnStartup function of my application. But when calling Show(), I get a NullReferenceException. This is thrown in RibbonProperties.GetLastVisibleWidth(DependencyObject element) when called with RibbonWindow.WindowsCommands.ItemsControl as parameter.

Here is how I create the RibbonWindow (MainWindow is derived from Fluent.RibbonWindow):
  public partial class App : Application
  {
    [STAThreadAttribute ()]
    [GeneratedCodeAttribute ( "PresentationBuildTasks", "4.0.0.0" )]
    public static void Main ()
    {
      var app = new App ();
      app.Run ();
    }

    protected override void OnStartup ( StartupEventArgs e )
    {
      base.OnStartup ( e );
      var window = new MainWindow ();
      window.Show ();
    }
  }
[FluentRibbonTest.zip](https://github.com/fluentribbon/Fluent.Ribbon/files/4319622/FluentRibbonTest.zip)

## batzen commented on 2020-03-11T18:06:08Z

The only case i know this happens is if the Generic.xaml from Fluent.Ribbon is not included as a merged dictionary in app.xaml, or by using code or in the windows merged dictionaries.

---

## Oliver2710 commented on 2020-03-12T09:49:23Z

Thanks for the quick response. Even though it does not directly solve the problem, it points to the right direction. When creating the RibbonWindow manually (like in my example in App.OnStartup()), the Generic.xaml must be added to the window's resources instead to the app.xaml resources. This solves the problem!

---

## batzen commented on 2020-03-12T13:45:35Z

If you plan to use more than one RibbonWindow you are better off adding generic.xaml to the merged dictionaries of your app. You can also do that in your startup method.
If you load the file in every window you get quite a performance issue and changing themes, in case you plan to add that, would have to be done for every single window.
