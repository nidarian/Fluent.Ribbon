## batzen commented on 2022-06-12T08:34:22Z

As Fluent.Ribbon itself targets .NET 5 the dependencies are also for .NET 5 and that's totally valid.
The most plausible cause for this is that you have another project that references either a different version of Fluent.Ribbon or ControlzEx.
That's the reason why I switched to central package versions everywhere a long time ago.
