## batzen commented on 2015-12-21T13:12:49Z

You copied the sample code. The sample code contains this

```
x:Class="Fluent.Sample.Foundation.Window"
```

in the xaml file. But your class is named `MainWindow` and your namespace is called `TestRibbon`.
To make it compile again in your project you need to change

```
x:Class="Fluent.Sample.Foundation.Window"
```

to

```
x:Class="TestRibbon.MainWindow"
```
