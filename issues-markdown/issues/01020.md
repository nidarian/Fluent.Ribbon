<blockquote>
<h2>[6.0.2] / 2022-04-13</h2>
<ul>
<li>Fixed <code>Update</code> command to use <code>net6.0</code></li>
<li>Fixed handling of common errors</li>
<li>Fixed assertion messages to only include argument expression when message is <code>null</code></li>
<li>Fixed log file pattern to use <code>-</code> instead of <code>:</code> for time</li>
<li>Fixed padding of target names in logging</li>
<li>Fixed logging to use <code>ExecutingTarget</code> instead of <code>Target</code> to reduce clashing</li>
<li>Fixed concurrent writing of shell-completion files</li>
<li>Fixed telemetry to check for interactive console</li>
<li>Fixed passing build instance for value injection in components</li>
<li>Fixed <code>ValueInjectionAttributeBase.GetMemberValue</code> to consider members from components</li>
<li>Fixed resolution of members from parameter files</li>
<li>Fixed reporting of exceptions in summary when not thrown from targets</li>
<li>Fixed naming for .NET SDK in bootstrapping scripts</li>
<li>Fixed GitHub Actions to use <code>GITHUB_TOKEN</code> instead of <code>GITHUB_CONTEXT</code></li>
<li>Fixed GitHub Actions assertion messages</li>
<li>Fixed missing output types for <code>ReportGeneratorTasks</code></li>
<li>Fixed missing arguments for <code>HelmTasks</code></li>
<li>Fixed missing arguments for <code>SonarScannerTasks</code></li>
<li>Fixed missing command for <code>KubernetesTasks</code></li>
<li>Fixed path resolution in <code>PowerShellTasks</code> to use PowerShell Core on non-Windows systems</li>
<li>Fixed missing runtime types in <code>NSwagTasks</code></li>
</ul>
