## chdft commented on 2015-05-04T13:47:14Z

I think the difference in color is the intended behavior. 
Other applications by Microsoft that use application menus (i.e. explorer in Windows 8.1) use the application menus background color (#F6F7F8) rather than the ribbons background color (#FFFFFF) for that rectangle.
The gray line in the application menu should line up with the border of the tabs in the ribbon bar (it does that in FluentTest and Windows explorer), but the ribbon tabs in your application seem to have no border at all.
Could it be, that you haven't added any tabs to your ribbon yet?

## batzen commented on 2015-05-04T18:00:08Z

To change the color of that rectangle you have to overwrite "RibbonBackgoundBrush" at least in the scope of the ApplicationMenu like so

```
<Fluent:ApplicationMenu.Resources>
    <SolidColorBrush x:Key="RibbonBackgoundBrush" Color="Red"/>
</Fluent:ApplicationMenu.Resources>
```

## batzen commented on 2015-05-20T11:24:14Z

That border color can be changed by overwriting "ContextMenuBarBorderBrush" but that will probably cause side effects on other controls contained in the menu.
The only real way to change this without side effects and without overwriting the template would be to introduce a new property like "PopupBorderBrush".

Feel free to implement such a property, change all themes accordingly and send me a pull request.
