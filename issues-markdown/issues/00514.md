# Issue #514: Detect Windows 10 app mode setting and adjust current AppTheme automatically

Windows 10 has "Light" and "Dark" as default "app modes" located in Settings -> Personalization -> Colors.

`ThemeManager` should be able to detect the selected "app mode" and adjust the current `AppTheme` automatically if user opted in to this new feature in `ThemeManager`.
