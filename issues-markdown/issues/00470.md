**SelectedTabIndex doesn't work**

Hi,
I'm trying to use Ribbon Property SelectedTabIndex="{Binding SelectedTabIndex}" to activate tab from ViewModel but it doesn't do anything.
I particularly want to select a group tab active after it's set to visible with binding from ViewModel because it doesn't activate automaticly after getting visible:

    <fluent:RibbonContextualTabGroup Header="{Binding CurrentDzial.Nazwa}" 
                                                 Visibility="{Binding DzialContextToolsVisible, Converter={StaticResource BoolToVisibilityConverter}}"
                                                 x:Name="DzialGroup" Background="Brown" BorderBrush="Brown" /> 

I have made it work with code behind:

       private void Ribbon_OnIsVisibleChanged(object sender, DependencyPropertyChangedEventArgs e)
        {
            var item = sender as RibbonTabItem;

            if (item == null)  return;
           if (item.IsLoaded && !item.IsSelected && (bool) e.NewValue)
            {
                item.IsSelected = true;
            }
            else if (!item.IsLoaded && item.Visibility == Visibility.Visible)
            {
                item.IsSelected = false;
                item.Visibility = Visibility.Collapsed;
            }
        }
and it works fine but when i have changed base class of MainWindow from RibbonWindow to MahApps MetroWindow it stops working altogether: TabGroups don't show at all, RibbonContextualTabGroup Visibility Binding seems to stop working.
Am i doing something wrong or there is an issue that needs to be fixed?
Thanks for help.

Selecting an item/tab by index should work.
Could you provide a repro for that?

If `RibbonContextualTabGroup` etc. don't show up you forgot to add a `RibbonTitleBar` to your `MetroWindow`.
Have a look at https://github.com/fluentribbon/Fluent.Ribbon/blob/develop/Fluent.Ribbon.Showcase/MahMetroWindow.xaml and https://github.com/fluentribbon/Fluent.Ribbon/blob/develop/Fluent.Ribbon.Showcase/MahMetroWindow.xaml.cs to get to know how to add one.
The bridge between those two is `IRibbonWindow`.
