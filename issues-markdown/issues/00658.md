## batzen commented on 2018-12-11T21:41:04Z

So i just had a look.
Just try to change your test app by removing the ribbon elements and change the inner buttons to
```
                <Button Width="100" Height="100" Content="{StaticResource Gears}" />
                <Button Width="100" Height="100" Content="{StaticResource Gears}" />
                <Button Width="100" Height="100" Content="{StaticResource Gears}" />
```
It will also only render the last button "icon" because a control, which `Path` is, can only have one parent.
If you change the ribbon button icons to the same code you used for the other brushes (Rectangle and VisualBrush) they will work as intended. Or you could try to use a `DrawingImage` instead of a simple `Path`.

## batzen commented on 2018-12-12T06:36:48Z

If you set Icon to a file/resource path the converter creates a new Image object.
If you set Icon to a Path object the converter essentially does nothing and just returns that object as it is. As Path is a FrameworkElement it can only have one parent. When using the same Path object in multiple places the last user/consumer of that object gets the parent and this causes your Path object only to be visible in one place.
If i extend the converter to convert Path/Shape objects to a DrawingImage, or something like that, it should be possible to display it in multiple places.

There is also more logic inside the converter to return frozen instances of images to enable reuse and also logic to extract images in the desired size from multi-frame images.
