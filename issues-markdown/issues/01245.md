# Issue #1245: Event IsVisibleChanged does not work in 11.0.0

After the update to version 11, the IsVisibleChanged event is no longer thrown on the RibbonContextualTabGroup object. 


`<Fluent:RibbonContextualTabGroup x:Name="scriptEditGroup" Header="Scripts" Visibility="{Binding Path=ScriptEditRibbon}" Background="Green"  BorderBrush="Green" IsVisibleChanged="TabVisibleChanged" />`


```
 private void TabVisibleChanged(object sender, DependencyPropertyChangedEventArgs e)
 {
     if (sender is not RibbonContextualTabGroup item) return;
     if (item.IsVisible)
         foreach (var tab in MainRibbon.Tabs)
         {
             if (tab.Group == item)
             {
                 MainRibbon.SelectedTabItem = tab;
                 break;
             }
         }
 }

```

The application is tab-based and depending on the tab displayed, different RibbonContextualTabGroup are shown and hidden. 

In the ViewModel:

```
[ObservableProperty]
[NotifyPropertyChangedFor(nameof(InternalUserRibbon))]
[NotifyPropertyChangedFor(nameof(SetttingsDefinitionRibbon))]
[NotifyPropertyChangedFor(nameof(MailEditorControlRibbon))]
[NotifyPropertyChangedFor(nameof(SettingEditRibbon))]
[NotifyPropertyChangedFor(nameof(InternalGroupRibbon))]
[NotifyPropertyChangedFor(nameof(FileAdapterRibbon))]
[NotifyPropertyChangedFor(nameof(IconEditRibbon))]
[NotifyPropertyChangedFor(nameof(CustomersAdapterRibbon))]
[NotifyPropertyChangedFor(nameof(TicketViewRibbon))]
[NotifyPropertyChangedFor(nameof(WorkbasketRibbon))]
[NotifyPropertyChangedFor(nameof(StageQueryRibbon))]
[NotifyPropertyChangedFor(nameof(StageOverviewRibbon))]
[NotifyPropertyChangedFor(nameof(ZabbixVersionRibbon))]
[NotifyPropertyChangedFor(nameof(ScriptEditRibbon))]
private MainTabItemViewModel? _selectedTabItem;

public Visibility InternalUserRibbon => GetVisibility(typeof(InternalUserControl));
public Visibility InternalGroupRibbon => GetVisibility(typeof(InternalGroupControl));
public Visibility SetttingsDefinitionRibbon => GetVisibility(typeof(SettingsDefinitionEditorControl));
public Visibility MailEditorControlRibbon => GetVisibility(typeof(MailEditorControl));
public Visibility SettingEditRibbon => GetVisibility(typeof(SettingsControl));
public Visibility FileAdapterRibbon => GetVisibility(typeof(FileAdapterControl));
public Visibility CustomersAdapterRibbon => GetVisibility(typeof(CustomerControl));
public Visibility IconEditRibbon => GetVisibility(typeof(IconLibControl));
public Visibility TicketViewRibbon => GetVisibility(typeof(TicketViewControl));
public Visibility WorkbasketRibbon => GetVisibility(typeof(WorkbasketControl));
```

If the visibility has changed, the IsVisibleChanged event was triggered. In the event, the focus is then set on the context item so that the user always sees the right buttons in their current tab.
