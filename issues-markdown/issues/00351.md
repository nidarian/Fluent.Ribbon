## chdft commented on 2016-11-15T18:46:30Z

I finally got around to investigate further:
This is apparently an issue with Intel HD graphics cards when some power saver features are enabled. I was able to reliably (well it occurred 8 of 8 times) reproduce it on a ThinkPad W540 with the dedicated graphics card disabled. When disabling the power saving features (I used a utility by Lenovo to do so), the issue wasn't reproducible any more. It seems reasonable to assume that similar features are available (although maybe not exposed in the UI) on other systems using similar hardware.

As a result, I would conclude that this is a quirk in the Intel HD Graphics driver and therefore not feasible to fix or reliably work around. As @batzen already suggested, switching to a non-dwm theme for your application (i.e. the Office 2013 theme) is probably the way to go.
Alternatively, you could use a regular `Window` in place of a `RibbonWindow` - although you would loose contextual tab headers, the quick access toolbar above the ribbon and the client area aero glass effect. You can see an example of this in the showcase application when you click "Open Regular Window" in the tab "Tests".

## KyanWang commented on 2018-12-28T09:03:07Z

      <!-- A list of the Windows versions that this application has been tested on and is
           is designed to work with. Uncomment the appropriate elements and Windows will

      <!--<supportedOS Id="{e2011457-1546-43c5-a5fe-008deee3d3f0}" />-->

      <!-- Windows 7 -->
      <!--<supportedOS Id="{35138b9a-5d96-4fbd-8e2d-a2440225f93a}" />-->
