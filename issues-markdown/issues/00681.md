## batzen commented on 2018-12-28T14:32:34Z

I made some improvements to the converter responsible for converting these shortcut paths to real images in version 7.0. Could you try the pre-release from nuget and check if you see an improvement?
The converter now will, if it can't locate a resource, display a warning icon at design time and an exception at runtime if it really can't find the resource.

Aside from that what you describe is not a compile time error but an intellisense/designer error instead.

## batzen commented on 2018-12-28T15:42:09Z

Guess why i implemented that "error" icon. Many people ran into this issue.
One thing you could try is to use a hard resource path.
So changing `"pack://application:,,,/resources/addUser.png"` to `"pack://application:,,,/Arcomat;component/resources/addUser.png"` should fix the issue.
