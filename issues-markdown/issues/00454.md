# Issue #454: RibbonWindow title not shown in correct position when using SizeToContent

- **State:** closed
- **Author:** Cubey2019
- **Created:** 2017-08-15T10:50:40Z
- **Closed:** 2017-09-05T17:14:43Z
- **Labels:** Bug :lady_beetle:

When using SizeToContent="Width" (or WidthAndHeight) the caption in the window title bar can appear offset to the right, in some cases overlapping with the minimise/maximise/close buttons. The problem corrects itself if you manually resize the window (just clicking the resize border is enough).

This is a screenshot of our application's title bar, before & after resize:
![caption](https://user-images.githubusercontent.com/26153437/29310740-e74f391a-81a6-11e7-9beb-ab571fe6663c.png)


I can also reproduce this in the showcase application (committed changes to branch 1d397719c641004d0092e22b3d3ad9f0523a5f17) although it's not as obvious:
![fluent caption](https://user-images.githubusercontent.com/26153437/29310773-0b91dada-81a7-11e7-8aa8-7c7f6acae4ae.png)
