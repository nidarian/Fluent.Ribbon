<p>This release includes improvements for Visual Studio 2022 and XamlStyler.Console.</p>

</ul>

<p>This release adds support for Rider 2023.2 (<a href="https://redirect.github.com/Xavalon/XamlStyler/issues/433">#433</a>). It also contains a bug fix addressing external configuration support in Rider (<a href="https://redirect.github.com/Xavalon/XamlStyler/issues/308">#308</a>).</p>
<h2>v3.2304.0</h2>
<p>This release adds support for Rider 2023.1 (<a href="https://redirect.github.com/Xavalon/XamlStyler/issues/418">#418</a>).</p>
<h2>v3.2208.1</h2>
<p>This release includes new features for Visual Studio 2017, 2019, and 2022.</p>
<ul>
<li>Adds option to ignore design-time reference prefix when reordering (<a href="https://redirect.github.com/Xavalon/XamlStyler/issues/306">#306</a>)</li>
<li>Adds support for Avalonia (.axaml) file extensions (<a href="https://redirect.github.com/Xavalon/XamlStyler/issues/300">#300</a>)</li>
</ul>
