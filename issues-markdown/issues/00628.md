## BendicoE commented on 2018-09-06T07:31:50Z

I found the problem:smiley:

My Visual Studio installation was missing the F# components. I thought I didn't need them, because I never use F# and it was not selected by default when I installed Visual Studio. However, a comment about F# in the Sdk.targets file (actually just above line 41 which caused the compiler error) led me to the conclusion that it might be needed anyway.

Running the Showcase app now. Looks great, packed with features!
