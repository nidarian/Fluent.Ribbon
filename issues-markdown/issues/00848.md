Hello,

if you use a colorful theme and maximize the window, then you can see the colored window-border in the left and right corner on the Ribbon as you can see in the following screenshot (they are marked with a red star):

![Demo Project](https://user-images.githubusercontent.com/10423894/92790291-f0046b00-f3ab-11ea-9b1e-0b0e959148a8.png)

If a "non-colorful" theme is selected everything looks fine eventhough the window is maximized.
You can quickly reproduce it with Fluent.Ribbon.Showcase.

### Environment

- Fluent.Ribbon 8.0.0 Showcase Project
