I'm trying to reuse the RibbonWindow trough out my application to have a consistent look with the ribbon style (for example for modal dialogs etc). However if I do not define a Ribbon element on the RibbonWindow, there is no window title and the content is overlapping with the window chrome. In the VS designer all looks fine.

Is there a workaround for this?

## batzen commented on 2015-06-15T16:18:04Z

It looks different because we can't really overwrite the way the designer renders the window. As you can see in your screenshots the buttons for minimizing, maximizing and closing the window are missing in the designer.
To really use the RibbonWindow you have to add a Ribbon to the Window.
There are ways to, kind of, hide the ribbon from the window then and that's the way I use it at work.
The RibbonWindow has a property called IsCollapsed which you should set to "true" and IsAutomaticCollapseEnabled should be set to "false" for a starting point.
