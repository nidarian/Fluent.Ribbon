## batzen commented on 2020-01-11T11:01:58Z

Well you are changing themes on the application level but include the resources on the window level.

You can solve this in two ways:
- move the resource includes from the window to app.xaml
- or change your thememanager code to not use Application.Current but your current window instead

I would suggest you use the first way as you'd have to do this for every window you want to change themes on if you'd go for way two.
