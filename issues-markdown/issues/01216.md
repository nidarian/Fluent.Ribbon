<details>
<summary>Release notes</summary>
<p><em>Sourced from <a href="https://github.com/nuke-build/nuke/releases">Nuke.Common's releases</a>.</em></p>
<blockquote>
<h2>8.1.2</h2>
<ul>
<li>Fixed exclusion of skipped target from lookup for skippable dependencies</li>
<li>Fixed resolution of empty environment variables to false</li>
<li>Fixed parallel execution to prefer logger from settings</li>
</ul>
<h2>8.1.1</h2>
<ul>
<li>Fixed nested solution folders in <code>StronglyTypedSolutionGenerator</code></li>
<li>Fixed whitespace arguments in <code>ArgumentStringHandler</code></li>
<li>Fixed output logging in parallel execution</li>
<li>Fixed exclusion of invoked targets from skipping</li>
<li>Fixed definite argument in <code>EntityFrameworkTasks</code></li>
</ul>
<h2>8.1.0</h2>
<ul>
<li>Added schema generation with references for <code>build.schema.json</code></li>
<li>Added deserialization of full objects from <code>parameters.json</code></li>
<li>Added <code>AbsolutePath</code> extension methods for <code>AddUnixSymlink</code>, <code>Copy*</code>, <code>Move*</code>, <code>Rename*</code></li>
<li>Added support for preprocessor directives in solution parsing</li>
<li>Added <code>Pattern</code> in favor of property in <code>LatestGitHubReleaseAttribute</code></li>
<li>Added <code>ConcurrencyGroup</code>, <code>ConcurrencyCancelInProgress</code>, <code>EnvironmentName</code>, <code>EnvironmentUrl</code> in <code>GitHubActionsAttribute</code></li>
<li>Added <code>DotnetPackagingTasks</code></li>
<li>Fixed invoked targets to not be excluded from skipping</li>
<li>Fixed stripping of hyphens in skipped target names</li>
<li>Fixed empty environment variables to be resolved as empty arrays</li>
<li>Fixed <code>EnableUnsafeBinaryFormatterSerialization</code> to be set through <code>AppContext</code></li>
<li>Fixed unquoting of multiple quoted arguments in <code>ArgumentStringHandler</code></li>
<li>Fixed using logger from settings in parallel execution</li>
<li>Fixed handling of duplicated NuGet package files</li>
<li>Fixed inclusion of original NuGet packages in requirements</li>
<li>Fixed GitHubActions to use latest action versions</li>
<li>Fixed <code>DotCoverTasks</code> and <code>EntityFrameworkTasks</code> tool path resolution</li>
<li>Fixed missing members in <code>GitHubActionsImage</code></li>
<li>Fixed missing properties in <code>GitLab</code></li>
<li>Fixed missing parameters in <code>AzurePipelines.SetVariables</code></li>
<li>Fixed missing arguments in <code>DotNetTasks</code></li>
<li>Fixed tool path in <code>CodecovTasks</code></li>
</ul>
</blockquote>
