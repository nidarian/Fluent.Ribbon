# Issue #614: Binding path error: Description property not found on MenuItem

- **State:** closed

- **Labels:** -

There is an annoying bug in FluentDefaultSystemMenuItemStyle that floods the output window in VS with "System.Windows.Data Error: 40 : BindingExpression path error" 

The bus is in the line:
DataTrigger Binding="{Binding Description, RelativeSource={RelativeSource Self}, Converter={x:Static converters:IsNullConverter.Instance}}" Value="False"

The standard MenuItem does not have a Description, only the Fluent menu items have one. So either is the style defined for the wrong type or if the style should be generic, add FallbackValue to suppress the cases where the source does not have a Description property.

Thanks
-Todor

### Environment

- Fluent.Ribbon __v7.0.0-alpha0388__
- Windows __10__
- .NET Framework __4.7__
