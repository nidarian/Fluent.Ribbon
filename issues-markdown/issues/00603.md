Spinner by default update value only by lostFocus.
I want update value when user input something. I try UpdateSourceTrigger=PropertyChanged, but it does not work

```

                SizeDefinition="Large,Large,Large"
                Margin="0,2,0,0"
                InputWidth="70"
                Minimum="1"
                Interval="1"
                Format="#"
                Value="{Binding Position, Delay=200, UpdateSourceTrigger=PropertyChanged}"/>
```

## batzen commented on 2018-08-18T17:51:11Z

That's because it get's very complicated when starting to validate/transfer values immediately.
The spinner is not a numeric textbox or something like that.
Even the spinner in Office does not transfer values immediately.
If you want a numeric input control which is capable of what you want have a look at https://mahapps.com/controls/numericupdown.html as far as i remember it supports that.
