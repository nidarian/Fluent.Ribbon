## batzen commented on 2019-01-08T15:17:52Z

Could you test the same with the preview version of 7.0?
It should display an error icon at design time if an icon can not be found during design time and throw an error at runtime if an icon can not be found.

The icon was not visible during design time in version 5.0.2.46 too, or was it visible?

The converter responsible for converting these "short" resource paths to real resource paths returns a frozen instance of the image starting with version 6.0 to avoid problems in case icons are re-used. When the frozen instance is created WPF trys to access the resource which causes the error you see. If you use the full `pack` URI the error should go away in all versions.
