# Issue #789: Opening gallery messes up InRibbonGallery resizing.

- **State:** closed
- **Author:** pschimmel
- **Created:** 2020-04-09T17:47:16Z
- **Closed:** 2020-04-13T11:32:40Z
- **Labels:** Bug :lady_beetle:
- **Original:** https://github.com/fluentribbon/Fluent.Ribbon/issues/789

There is a problem with the resizing of the InRibbonGallery. As long as the gallery is closed, there is no problem. But once it is opened and closed again, the sizing is messed up. See the following screenshots. The gallery is set to MaxItemsInRow="5" and MinItemsInRow="1". For the first screenshot I reduced the width of the window that the number of shown gallery items are reduced to 3. Then I just open and close the gallery.

![Layouts1](https://user-images.githubusercontent.com/9028723/78924547-57835b00-7a9a-11ea-81e3-d7017c85c31b.png)

Open gallery:
![Layouts2](https://user-images.githubusercontent.com/9028723/78924555-5a7e4b80-7a9a-11ea-9c37-a0cd0d539aaf.png)

Close gallery: 
![Layouts3](https://user-images.githubusercontent.com/9028723/78924563-5ce0a580-7a9a-11ea-992b-d3177c5b1903.png)

Now more items are shown in the gallery than before and the size of the remaining controls is reduced to adjust the sizing.

This is probably related to issue #765.

- Fluent.Ribbon v7.1.0
- Windows 10
- .NET Framework 4.7.2
