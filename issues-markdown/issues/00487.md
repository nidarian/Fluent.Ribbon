## batzen commented on 2017-11-03T17:03:06Z

A lot changed in version 6 regarding colorization. So you have to use the pre-release from nuget to get this.
Have a look at the showcase application there is a sample which can be reached through the TabControl contained in the content area, on the "Tests" tab there is a button labeled "Open Ribbon-Window (colorized)" which shows different colors.
The code can be found at https://github.com/fluentribbon/Fluent.Ribbon/blob/develop/Fluent.Ribbon.Showcase/RibbonWindowColorized.xaml
