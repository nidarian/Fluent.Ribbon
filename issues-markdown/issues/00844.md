## batzen commented on 2020-09-06T07:38:04Z

It's saved in the isolated storage under `%LOCALAPPDATA%\IsolatedStorage`.
If the user changes the location of the QuickAccessToolbar during runtime it should be saved and restored on the next run.
If it stays at one location it might be that it's overwritten in the application itself.
