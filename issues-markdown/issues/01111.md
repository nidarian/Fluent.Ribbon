## batzen commented on 2023-03-05T15:20:08Z

WindowStyle = None means, no native window border.
If you still want to have a border you'll have to use the glow border.
Just set `PreferDWMBorderColor="False"` and `CornerPreference="DoNotRound"`.
The glow border does not support rounded corners.
