## batzen commented on 2020-07-30T15:28:58Z

The layout of the window title is centered intentionally to be consistent with office.
If you want the title to be left aligned you can change `HeaderAlignment` on `RibbonTitleBar` which you can access from `Ribbon.TitleBar`.
There is currently an issue which causes changes to that property at runtime to only apply on window resizes, but that will be fixed in the next version.
