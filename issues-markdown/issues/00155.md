When item from Toolbar Dropdown is added with has click event the Click Event is not trigered (do not work).

How to repeat:
Modify Fluent Ribbon source file (TestContent.xaml):

>  <Fluent:RibbonGroupBox Fluent:KeyTip.Keys="ZC"
>                                        Header="Normal KeyTips"
>                                        Name="ZC">
>  ....
> <Fluent:MenuItem Fluent:KeyTip.Keys="O"
> Header="Orange"
> Icon="pack://application:,,,/FluentTest;component/Images/Orange.png"
> 
> **Click = MenuItem_OnClick** />   //Added click event to Orande menu item

And in cs code add method it self:

> private void MenuItem_OnClick(object sender, RoutedEventArgs e)
>         {
>             MessageBox.Show("Menu 1 is Clicked");
>         }

 Then if you add Parent levels Menu items with the Orange Menu as a child - the Click event will work. But if you Right Click on "Orange" menu item and add it to QAT - after this try to click QAT "Orange" icon, then the Orange menu Click Event is not fired.

## batzen commented on 2015-08-23T21:37:40Z

That's because click events are not always forwarded to their original control.

I would suggest you use Commands instead of Click events. Commands are always forwarded/copied.
The problem with copying event registrations or forwarding them is that those cause memory leaks because the original control, which creates the quick access item and has to forward the events, is currently not notified when that item is destroyed/remove from the QAT.
