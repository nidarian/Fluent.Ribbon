---

## batzen commented on 2015-07-06T20:14:39Z

Just set "Icon" to your desired object. As far as I can see "Icon" is of type "object" and is represented by a ContentPresenter.

```
                <fluent:Button>
                    <fluent:Button.Icon>
                        <Rectangle Fill="Green" Height="20" Width="20" />

                    </fluent:Button.Icon>
                </fluent:Button>
```


---

## batzen commented on 2015-07-10T17:08:41Z

You should always set Icon and LargeIcon

```
                    <Fluent:Button>
                        <Fluent:Button.Icon>
                            <Rectangle Fill="Green" Height="20" Width="20" />
                        </Fluent:Button.Icon>
                        <Fluent:Button.LargeIcon>
                            <Rectangle Fill="Green" Height="20" Width="20" />
                        </Fluent:Button.LargeIcon>                        
                    </Fluent:Button>
```
