## batzen commented on 2026-05-30T05:48:44Z

I just laid the building blocks for this.
Those should unlock the basics
To get a specific icon size in QAT you can now use, for example:
```
<Fluent:QuickAccessMenuItem IsChecked="True">
    <Fluent:Button ToolTip="Precast Structures"
                   Size="Large"
                   SizeDefinition="Large"
                   LargeIcon="{DynamicResource Fluent.Ribbon.Images.DefaultPlaceholder}"
                   Fluent:RibbonProperties.CustomIconSize="48,48"
                   Fluent:RibbonProperties.QATIconSize="Custom" />
</Fluent:QuickAccessMenuItem>
```

To fully achieve what you are trying you would also have to increase `TitleBarHeight` on `RibbonWindow` and you would have to provide dedicated styles for each type of control you want to use in the QAT as the desired height etc. is controlled by style triggers.
Button for example uses 22 for it's height when it's size should be small, which is still, the desired size for all QAT items.
