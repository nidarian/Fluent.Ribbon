## batzen commented on 2024-07-06T08:08:47Z

That's exactly the same as for regular `MenuItem`.
If you want to get rid of that space you'd have to provide your own template.

The reason why there is no trigger that hides the icon is:
If you would have a mixed list of items, some with an icon and some without, the layout would be inconsistent.
