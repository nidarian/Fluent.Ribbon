<details>
<summary>Changelog</summary>
<p><em>Sourced from <a href="https://github.com/nuke-build/nuke/blob/develop/CHANGELOG.md">Nuke.Common's changelog</a>.</em></p>
<blockquote>
<h2>[6.1.1] / 2022-06-21</h2>
<ul>
<li>Fixed output encoding in <code>Nuke.GlobalTool</code> to be UTF-8</li>
<li>Fixed telemetry to handle Git repositories without remote</li>
<li>Fixed <code>GitRepository.HttpsUrl</code> and <code>SshUrl</code> when <code>Endpoint</code> is null</li>
<li>Fixed <code>ShutdownDotNetServerBuildAttribute</code> to timeout after 15 seconds</li>
</ul>
<h2>[6.1.0] / 2022-06-14</h2>
<ul>
<li>Removed extended setup wizard</li>
<li>Changed <code>Nuke.GlobalTool</code> to use <code>Spectre.Console</code></li>
<li>Deprecated <code>CheckBuildProjectConfigurationsAttribute</code></li>
<li>Added single-file packaging and execution</li>
<li>Added output customization via <code>NukeBuild.WriteLogo</code>, <code>WriteTarget</code>, and <code>WriteSummary</code></li>
<li>Added second-chance registration for MSBuild from .NET CLI</li>
<li>Added submodule support in GitHub Actions, Space Automation, and AppVeyor</li>
<li>Added <code>NukeBuild.BuildAssemblyFile</code> property</li>
<li>Added generic <code>EnvironmentInfo.SetVariable</code></li>
<li>Added support for Bitbucket</li>
<li>Added GitHub Actions support for <code>fetch-depth</code></li>
<li>Fixed <code>default_target</code> replacement in help text</li>
<li>Fixed parameter padding and line breaks in help text</li>
<li>Fixed <code>Assert</code> methods to accept <code>IReadOnlyCollection</code></li>
<li>Fixed fatal failure of <code>MSBuildLocator</code></li>
<li>Fixed missing MSBuild registration when using <code>ProjectExtensions</code></li>
<li>Fixed <code>NuGetPackageResolver</code> performance by reading metadata from <code>.nuspec</code> files</li>
<li>Fixed <code>GitRepository</code> initialization when remote is not set</li>
<li>Fixed exception for duplicated keys in TeamCity property files</li>
<li>Fixed missing arguments for <code>DotNetTasks</code></li>
</ul>
</blockquote>
