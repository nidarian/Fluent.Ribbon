# Issue #160: Invisible first tab is selected when selected tab becomes invisible

- **State:** closed
- **Author:** nishy2000
- **Created:** 2015-08-26T07:33:52Z
- **Closed:** 2015-08-26T11:14:40Z
- **Labels:** Bug :lady_beetle:
- **Original:** https://github.com/fluentribbon/Fluent.Ribbon/issues/160

Invisible first tab is selected when a selected tab becomes invisible.
As result, contents of an invisible tab is shown.
- Pre-condition:
  The first tab is **invisible** and non-selected.
  The second tab is visible and non-selected.
  The third tab is **visible** and **selected**.
- Transition:
  The third tab becomes **invisible**.
  by code-behind.
  Ex.) Hide a selected contextual tab or a contextual tab group that has a selected contextual tab. 
- Post-condition(current):
  The first tab is invisible and **selected**.
  The second tab is visible and non-selected.
  The third tab is **invisible** and **non-selected**.
- Post-condition(expected):
  The first tab is invisible and non-selected.
  The second tab is visible and **selected**.
  The third tab is **invisible** and **non-selected**.
## Code:

Fluent.Ribbon-3.5.0\Fluent.Ribbon-3.5.0\Fluent\Controls\RibbonTabItem.cs
RibbonTabItem.OnVisibilityChanged()
`item.TabControlParent.SelectedItem = item.TabControlParent.Items[0];`

``` C#
        // Handles visibility changes
        private static void OnVisibilityChanged(DependencyObject d, DependencyPropertyChangedEventArgs e)
        {
            var item = d as RibbonTabItem;

            if (item == null)
            {
                return;
            }

            if (item.Group != null)
            {
                item.Group.UpdateInnerVisiblityAndGroupBorders();
            }

            if (item.IsSelected
                && (Visibility)e.NewValue == Visibility.Collapsed)
            {
                if (item.TabControlParent != null)
                {
                    if (item.TabControlParent.IsMinimized)
                    {
                        item.IsSelected = false;
                    }
                    else
                    {
                        // HERE
                        // visibility of Items[0] has been ignored.
                        item.TabControlParent.SelectedItem = item.TabControlParent.Items[0];
                    }
                }
            }
        }
```
