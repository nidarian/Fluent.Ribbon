Please recall the `FixWindowChromeBugForMaximizedWindow()` method found in **v3.6.0.221**. I'm currently investigating an extremely rare crash where the stack trace merely points to an `UpdateWindowPos` call. The error message tells me that there could perhaps exist an infinite loop of calls to `PostMessage` or something like that. Yeah, it's hard to analyze... But!

Looking at the source code for v3.6.0.221 I found this `FixWindowChromeBugForMaximizedWindow()` method which is being called when the window is being maximized. It calls `MoveWindow` twice which, I guess, could then re-trigger the `WM_SIZE` message hook?

**Is it even remotely possible that this old hack could cause this type of error?**
