## GeertvanHorrik commented on 2014-11-04T21:00:27Z

1) You should use it after you have built your software. It double checks if the checksum of the files in the pdb file match the ones on disk ("source control"). Since these are generated files (and the demo app anyway), you can ignore them.

2) You should just included your pdb files in the nuget and all should work automatically.

3) Since there is no specific commit specified to the command line, it will automatically use the latest commit on the current branch for you.
