# Issue #1170: The first item is highlighted when DropDown is opened by mouse interaction in DropDownButton and SplitButton

- **Created:** 2023-09-11T09:09:16Z
- **Closed:** 2024-05-01T14:43:24Z

The first focusable item (MenuItem) in controls with dropdown (DropDownButton, SplitButton) is highlighted (focused) when the dropdown is opened.
An item should be highlighted on user interaction, e.g. navigating with the keyboard.

---
### Environment

- Fluent.Ribbon 10.0.0
- Windows 10
- .NET Framework 4.8
