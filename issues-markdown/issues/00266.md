I have got some BackstageTabIitems. 
For each of them the content should be a scrollviewer and an header bound to BackstateTabItem's Header property.

This works:

```
<Fluent:BackstageTabItem Header="Account">
    <ScrollViewer>
        <Grid>
            <StackPanel>
                <TextBlock Margin="43" FontSize="36" Foreground="#FF444444" Text="{Binding Path=Header, 
            RelativeSource={RelativeSource AncestorType={x:Type Fluent:BackstageTabItem}}}"/>

            </StackPanel>
        </Grid>
    </ScrollViewer>
</Fluent:BackstageTabItem>

```

By the way to avoid duplication i created a new style as follows but binding to Header does not seem to work. In facts no binding works.

```
    <Style x:Key="{x:Type Fluent:BackstageTabItem}" TargetType="{x:Type Fluent:BackstageTabItem}">
        <Setter Property="ContentTemplate">
            <Setter.Value>
                <DataTemplate>
                    <ScrollViewer>
                        <Grid>
                            <StackPanel>
                                <TextBlock Margin="43" FontSize="36" Foreground="#FF444444" Text="{Binding MyText}"/>
                                <TextBlock Margin="43" FontSize="36" Foreground="#FF444444" Text="{Binding Path=Header, Mode=TwoWay, RelativeSource={RelativeSource FindAncestor, AncestorType={x:Type Fluent:BackstageTabItem}}}"/>

                                <ContentControl Content="{TemplateBinding Content}"></ContentControl>
                            </StackPanel>
                        </Grid>
                    </ScrollViewer>
                </DataTemplate>
            </Setter.Value>
        </Setter>
    </Style>
```

What am I doing wrong? Can you please help?

## batzen commented on 2016-02-10T17:08:35Z

You'd get the same problem with a regular TabControl.
Binding to the TabItem inside it's content via RelativeSource yields the same binding error as it does with fluent.

As to your binding to "MyText", you have to set the content of the BackstageTabItem to your desired data.
