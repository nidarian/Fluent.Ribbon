# Issue #332: Visual glitches in InRibbonGallery with an ObservableCollection as ItemSource

- **State:** closed
- **Author:** dymanoid
- **Created:** 2016-07-15T09:28:08Z
- **Closed:** 2016-07-22T06:00:11Z
- **Labels:** already fixed in newer version
- **Original:** https://github.com/fluentribbon/Fluent.Ribbon/issues/332

When using an ObservableColletion as an ItemSource for the InRibbonGallery, there are some drawing issues after adding new items into the source collection. The new items appear in the gallery, but they are not properly scaled and positioned (e.g. overlap the already existing items). The gallery itself doesn't resize to match the new items' count.
After opening and closing the drop-down, the gallery resizes and repaints itself and finally looks as intended.

Can be easily reproduced with the showcase app - just replace the type of the MainViewModel.DataItems (make it an ObservableCollection<GallerySampleDataItemViewModel>) and add a Button with a Click event handler to add new items into source collection. Best observed when the gallery is set to CanCollapseToButton="False" and the initial count of the items in the MainViewModel.DataItems is 1 to 3. 
## 
### Environment
- Fluent.Ribbon 4.0.3.394
- Theme default (Generic)
- Windows 7 Pro
- .NET Framework 4.5.2
