# Issue #700: MenuItem does not show all text

- **State:** closed
- **Author:** korneliuscode
- **Created:** 2019-02-19T13:19:18Z
- **Closed:** 2019-03-10T17:05:56Z
- **Labels:** Question :question:
- **Original:** https://github.com/fluentribbon/Fluent.Ribbon/issues/700

Hi,
I use a DropDownButton to show a few data bound MenuItems and one fixed MenuItem.
The issue is, that the text of all data bound MenuItems is only displayed to the text width of the very first MenuItem. If there is a long text, most other fit. If a short one is on top, all others get cut to that lenght. The mouse over highlighting uses full available width.
```
<Fluent:DropDownButton Header="{x:Static res:Resources.Account}" SizeDefinition="Large,Middle,Small" ClosePopupOnMouseDown="False">
	<Fluent:Gallery ItemsSource="{Binding MyItems}" MaxItemsInRow="1" Selectable="False">
		<Fluent:Gallery.ItemTemplate>
			<DataTemplate>
				<MenuItem IsChecked="{Binding IsChecked}" Header="{Binding Text}" Command="{Binding ToggleCommand}" Margin="0" />
			</DataTemplate>
		</Fluent:Gallery.ItemTemplate>
	</Fluent:Gallery>
	<MenuItem Header="{x:Static res:Resources.All}" Command="{Binding CheckAllCommand}" />
</Fluent:DropDownButton>
```

### Environment

## batzen commented on 2019-03-02T17:29:02Z

You have to add `Orientation="Vertical"` to the gallery. Otherwise it's horizontal which means the width of the first item defines the width of all following items.
