## batzen commented on 2019-03-29T17:21:39Z

Just had a look at your sample and it's exactly what i was talking about.

The Style for MenuItem was previously, by accident, overwritten by Fluent.Ribbon.
That got fixed and now only the Style for Fluent:MenuItem is set by Fluent.Ribbon.
So what you are observing is because the default WPF style for MenuItem does not convert your PackUri to a proper icon/image.
What you are looking for is the `ObjectToImageConverter` from Fluent.Ribbon which takes care of converting PackUri etc. to an Image object.

## batzen commented on 2019-03-29T17:48:08Z

What would you think about the following usage?
```
<MenuItem Header="System.Windows.Controls.MenuItem" Icon="{fluent:ObjectToImageConverter 'pack://application:,,,/RibbonIssue;component/Images/Tools/NavForward.png'}"/>
<MenuItem Header="System.Windows.Controls.MenuItem" Icon="{fluent:ObjectToImageConverter 'pack://application:,,,/RibbonIssue;component/Images/Tools/NavForward.png', '16,16'}"/>
<MenuItem Header="System.Windows.Controls.MenuItem" Icon="{fluent:ObjectToImageConverter 'pack://application:,,,/RibbonIssue;component/Images/Tools/NavForward.png', '16,16', {Binding RelativeSource={RelativeSource Self}}}"/>
```

Explanation for the lines:
1. Just take the icon and use it in it's present size
2. Try to make the icon 16x16
3. Try to make the icon 16x16 but take the DPI of the target object into account when trying to extract the icon

Making this possible would only require minimal changes to the converter i mentioned and i would include that in version 7.0 if it helps you.
