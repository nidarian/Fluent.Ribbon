## batzen commented on 2020-09-19T20:24:24Z

Preventing the click does not prevent other ways to select the tab. In addition to a mouse click it can be a key tip, mouse wheel scrolling or other keyboard input.
The only reliable way to prevent tab selection is by disabling or hiding the tab.

## DavidHollman commented on 2020-09-22T12:23:42Z

@batzen just another thought... I wonder if adding a command to the tab would be a good approach? In my app I use an attached property to set a command on each tab. If the command cannot be executed, the tab is disabled. This might be a nice feature to eventually have built-in (though the AP works perfectly fine).

maybe this could work for you also.

```
 public class CommandAttachedProperties : DependencyObject
    {
        //////////////////////////////////////////////////////////////////////////////////

        /// <summary>
        ///  This attached property allows you to bind it to any ICommand, and then it
        ///  will set IsEnabled based on the executable status of the command. This is
        ///  useful to de/activate controls which don't take a command natively.
        /// </summary>

        public static readonly DependencyProperty IsEnabledCommandProperty =
            DependencyProperty.RegisterAttached("IsEnabledCommand", typeof(ICommand), typeof(CommandAttachedProperties), new PropertyMetadata(IsEnabledCommandChanged));

        public static ICommand GetIsEnabledCommand(DependencyObject d) => (ICommand)d.GetValue(IsEnabledCommandProperty);
        public static void SetIsEnabledCommand(DependencyObject d, ICommand value) => d.SetValue(IsEnabledCommandProperty, value);

        private static void IsEnabledCommandChanged(DependencyObject d, DependencyPropertyChangedEventArgs args)
        {
            EventHandler handler = (o, e) => SetIsEnabled((ICommand)o, d);

            var oldCmd = args.OldValue as ICommand;
            if (oldCmd != null)
            {
                oldCmd.CanExecuteChanged -= handler;
            }

            var newCmd = args.NewValue as ICommand;
            if (newCmd != null)
            {
                newCmd.CanExecuteChanged += handler;
                handler(newCmd, EventArgs.Empty);
            }
        }

        private static void SetIsEnabled(ICommand cmd, DependencyObject d)
        {
            var u = d as UIElement;

            if (u != null)
            {
                u.IsEnabled = cmd.CanExecute(null);
            }
        }

        //////////////////////////////////////////////////////////////////////////////////
    }

```

(I probably found or adapted this code from somewhere else, so credit is owed elsewhere; though any errors are probably mine!)

Here it is in use on a tab item:

```
            <local:SomeDerivedTabItem
                View:CommandAttachedProperties.IsEnabledCommand="{Binding Commands.GeneralTab_SelectTab}"
                />
```

IIRC the AP could be used on any `UIElement`, not only `RibbonTabItems.`
