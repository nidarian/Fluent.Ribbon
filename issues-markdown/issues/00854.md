# Issue #854: Arrow button not displayed when ribbon wider than window width

- **State:** closed
- **Author:** MarcelVersteeg
- **Created:** 2020-10-10T08:13:11Z
- **Closed:** 2020-11-29T09:42:21Z
- **Labels:** already fixed in newer version
- **Original:** https://github.com/fluentribbon/Fluent.Ribbon/issues/854

When the window containing the ribbon is resized such that the minimum ribbon width is larger than the window width, small arrows should appear on the ribbon to allow scrolling of the ribbon inside the window.

I have downloaded the latest code base of Fluent.Ribbon to see whether the ShowCase application behaves the same. I found out that the issue is solved in the latest code base, but when I replace the compiled Fluent.dll with the binary from the version 8.0.0 NuGet package, the arrow also disappears in the ShowCase application.
