How do you change the base color of a theme? I.e. I think the light blue theme is nice, but I want to change the blue accent to some custom color. Previously in v6, I could accomplish this using ThemeManager and a custom theme as described in the documentation. Now, **using v7 my colors are never used**. Instead I see the default light blue.

I followed the guide [here](https://fluentribbon.github.io/documentation/styles_since_7) to create my v7 theme. I can see that it is indeed applied in `OnStartup`, but the colors don't react. Ideas?

_App.xaml:_

```xml
<ResourceDictionary.MergedDictionaries>
  <ResourceDictionary Source="pack://application:,,,/Fluent;Component/themes/generic.xaml" />
  <!-- I tried adding my custom theme here. No success... -->
```

_App.xaml.cs:_
```c#
Fluent.ThemeManager.AddTheme(
   new Uri("pack://application:,,,/MyExeNamespace;component/Resources/MyAccent.xaml"));
Fluent.ThemeManager.ChangeTheme(this, "MyThemeName");
// Theme is applied, but colors are not updated!
```

_MyAccent.xaml:_

```xml
<ResourceDictionary xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
                    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
                    xmlns:options="http://schemas.microsoft.com/winfx/2006/xaml/presentation/options"
                    xmlns:system="clr-namespace:System;assembly=mscorlib">
    <system:String x:Key="Theme.Name">MyThemeName</system:String>
    <system:String x:Key="Theme.DisplayName">Red As Hell</system:String>
    <system:String x:Key="Theme.BaseColorScheme">Light.Blue</system:String>
    <system:String x:Key="Theme.ColorScheme">Blue</system:String>
    <SolidColorBrush x:Key="Theme.ShowcaseBrush" Color="Red" options:Freeze="True" />
    <!-- COLORS -->

    <!-- Accent colors -->
    <Color x:Key="Fluent.Ribbon.Colors.AccentBaseColor">Red</Color>
    <!--80%-->
    <Color x:Key="Fluent.Ribbon.Colors.AccentColor80">Red</Color>
    <!--60%-->
    <Color x:Key="Fluent.Ribbon.Colors.AccentColor60">Red</Color>
    <!--40%-->
    <Color x:Key="Fluent.Ribbon.Colors.AccentColor40">Red</Color>
    <!--20%-->
    <Color x:Key="Fluent.Ribbon.Colors.AccentColor20">Red</Color>

    <Color x:Key="Fluent.Ribbon.Colors.HighlightColor">Red</Color>

    <!-- And the stuff listed in the documentation... -->
</ResourceDictionary>
```
