# Issue #396: Ribbon button labels are cut if system font size is increased

- **State:** closed
- **Author:** pjahr
- **Created:** 2017-02-02T14:13:31Z
- **Closed:** 2018-07-07T13:55:38Z
- **Labels:** WontFix :-1:
- **Original:** https://github.com/fluentribbon/Fluent.Ribbon/issues/396

If the default OS font size used in dialogs and windows is increased, some of the labels in the ribbons child controls are cut.

![image](https://cloud.githubusercontent.com/assets/3593785/22552452/4a513072-e959-11e6-9d12-b371c70ddbf4.png)

This is not related to DPI scaling (which is working fine). To reproduce, open 'Window Color and Appearance', click the message box and increase the font size. The problem seems to be the hard-coded heights in the templates of RibbonGroupBox and some of the button controls.

---
### Environment

- Fluent.Ribbon 4.0.3 (5.0.0)
- Windows 7 Pro SP1 x64
- .NET Framework 4.6.1
