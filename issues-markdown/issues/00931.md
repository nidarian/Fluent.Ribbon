Control the state transition of RibbonGroupBox by ReduceOrder

The state transition of RibbonGroupBox by ReduceOrder is always Large <-> Middle <-> Small <-> Collapsed.
I want to be able to customize this.
For example
- When Middle is not required (Large <-> Small <-> Collapsed)
- When Middle and Small are not required (Large <-> Collapsed)
- When Collapsed is not required (Large <-> Middle <-> Small)
- And so on.

I suggest adding a StateDefinition property to RibbonGroupBox to achieve the above.

- StateDefinition can be set to a combination of Large, Middle, Small, Collapsed values.
- The separator is one of "", ",", ";", "-", ">".
- The order in which the values are listed has no meaning. The state transition is always a large state <-> a small state.
- The default value of StateDefinition is "Large, Middle, Small, Collapsed". Therefore, this enhancement does not affect existing behavior.

Example of use
```
<Fluent:RibbonTabItem Header="Toolbars"
                      KeyTip="TO"
                      ReduceOrder="Clipboard,Clipboard,Group, Group, Group, Font, Font, Font, Font,B,A,A,A,(A),(A),(A),Clipboard,Font,B,B,(A),C,(A),(A)">
    <Fluent:RibbonGroupBox x:Name="Font"
                           Header="Font"
                           KeyTip="F"
                           StateDefinition="Large,Middle,Small"
                           IsLauncherVisible="True"
                           LauncherClick="OnLauncherButtonClick"
```
