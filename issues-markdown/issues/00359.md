## batzen commented on 2016-10-15T12:04:05Z

Creating issues is the only way on GitHub do ask questions.
For simple questions you could also visit the fluent.ribbon gitter-channel at https://gitter.im/fluentribbon/Fluent.Ribbon
1. Use it at the level you prefer, but to make it work globally in your application/window you should attach it to the window, as using inputbinding on the ribbon only works when the ribbon has focus, as far as i remember how it works in WPF.
2. Fluent.Ribbon has no special functionality, except KeyTips, for this.
