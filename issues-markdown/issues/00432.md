## batzen commented on 2017-05-09T15:43:41Z

You can activate per monitor DPI for Fluent.Ribbon by using

```
<runtime>
    <AppContextSwitchOverrides value = "Switch.System.Windows.DoNotScaleForDpiChanges=false"/>
  </runtime>
```

But that causes some issues with controls on/in the window chrome like Minimize/Maximize/Close etc..
I will investigate those issues and fix them.
