Please, see video. In the case of bad quality on site, download on computer. https://yadi.sk/d/115MjfGK3E5Tqc

Our case is
```
<fluent:ComboBox Name="FontFamilyCombobox"
                                             SizeDefinition="Small"
                                             Width="110"
                                             MaxDropDownHeight="500"
                                             Style="{StaticResource SystemFontCombobox}"
                                             SelectedValuePath="Source"
                                             SelectedValue="{Binding Font.Family, Mode=OneWay}">
                                <i:Interaction.Triggers>
                                    <i:EventTrigger EventName="SelectionChanged">
                                        <i:InvokeCommandAction Command="{Binding SetFontFamilyCommand}"
                                                               CommandParameter="{Binding ElementName=FontFamilyCombobox, Path=SelectedItem.Source}" />
                                    </i:EventTrigger>
                                </i:Interaction.Triggers>
                            </fluent:ComboBox>
```

In addition
```
<Style x:Key="SystemFontCombobox"
                   TargetType="ComboBox">
                <Style.Resources>
                    <CollectionViewSource x:Key="Fonts"
                                          Source="{Binding Source={x:Static Fonts.SystemFontFamilies}}">
                        <CollectionViewSource.SortDescriptions>
                            <componentModel:SortDescription PropertyName="Source" />
                        </CollectionViewSource.SortDescriptions>
                    </CollectionViewSource>

                    <ItemContainerTemplate x:Key="FontTemplate">
                        <TextBlock FontSize="16"
                                   Width="220"
                                   FontFamily="{Binding Source}"
                                   Text="{Binding Source}"
                                   ToolTip="{Binding Source}" />
                    </ItemContainerTemplate>
                </Style.Resources>
                <Setter Property="ItemsSource"
                        Value="{Binding Source={StaticResource Fonts}}" />
                <Setter Property="ItemTemplate"
                        Value="{StaticResource FontTemplate}" />
            </Style>
```


Note: in version 3.6.1.236 such issue is absent

---
### Environment

- Fluent.Ribbon v4.0.3.394
- Theme Office2013 (Component/Themes/Office2013/Generic.xaml)
- Windows Server 2012R2
- .NET Framework 4.6.1
