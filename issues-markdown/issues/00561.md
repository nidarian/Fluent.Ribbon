## batzen commented on 2018-04-16T14:13:22Z

It's not possible to show a real MahApps progress dialog because the backstage uses an adorner and MahApps uses a completely different approach with containers embedded into the window itself.
These approaches are incompatible. Thus it's the easiest to just show an adorner above the backstage and render a custom progress dialog there.

To give you an idea of how this can be done i added some sample code to the showcase application with https://github.com/fluentribbon/Fluent.Ribbon/commit/60878cc8109f40ec2744a4d24915d7dd6e589d95.
Please have a look at that code and give some feedback ;-)
