# Issue #541: XamlParseException in VS Designer when defining Generic Theme in UserControl

- **State:** closed
- **Author:** hybrid2102
- **Created:** 2018-03-05T09:50:20Z
- **Closed:** 2018-05-10T09:55:26Z
- **Labels:** help wanted
- **Original:** https://github.com/fluentribbon/Fluent.Ribbon/issues/541

Hi all,
I have a Ribbon inside a UserControl, wich will be loaded into a MetroWindow at runtime.
When I open my UserControl in VS, I can't see the ribbon because of the lacking of the Generic Theme.

If i add, temporary for designing purposes, the resource dictionary in my UC resources...
`<ResourceDictionary Source="pack://application:,,,/fluent;Component/Themes/Generic.xaml" />`
 The VS designer stops loading, with this message:

> "XamlParseException: Could not load file or assembly 'MyApplication, Culture=neutral' or one of its dependencies. The system cannot find the file specified."

I remember to be used to use this trick (temporary specify the generic theme in my uc) to actually see the ribbon in VS Designer some time ago, but from some time I can't use it anymore.
Any hints?
Thank you for the support and for the awesome project.

---
### Environment

- Visual Studio __2017 v15.5.7__
- Fluent.Ribbon __v6.1.0.233__
- Windows __Server 2012 R2__
- .NET Framework __4.7.1__
