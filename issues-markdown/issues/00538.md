## batzen commented on 2018-03-03T05:59:31Z

paket = enhanced nuget https://fsprojects.github.io/Paket/
cake = build automation system https://cakebuild.net/
appveyor = continuous integration https://www.appveyor.com/

The build script fails because it tries to make use of msbuild's ability to run "dotnet restore" by itself, thus trying to call msbuild with a restore target. Somehow this fails on your machine, even though your studio version is higher than mine. That's also the reason why studio is unable to build the project/solution standalone. Maybe the dotnet core workload is not fully installed on your machine or something changed in vs 15.6.
A manual dotnet restore helps in this case. ;-)

This project switched to the sdk-csproj format, which is not yet fully ready for WPF projects and needs some workarounds/additions to even build. Microsoft will add out of the box support for WPF with VS 16.0 i think.
