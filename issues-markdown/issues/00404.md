## Alisaunder commented on 2017-03-10T16:01:42Z

Hey Madcat try doing this It works for me just place the code in your Xaml for the window you wanrt to display the help on. The icon is simply 22x22 Image of the questionmark. 
```<Fluent:RibbonWindow.WindowCommands>
       <Fluent:WindowCommands>
              <Fluent:WindowCommands.Items>
                     <Fluent:Button Icon="pack://application:,,,/MHManager;Component/Resources/Images/help22x22.png"
                                    HorizontalAlignment="Left"
                                    Width="Auto"
                                    Height="Auto"
                                    Size="Small"
                                    VerticalAlignment="Center"
                                    Margin="0"
                                    ToolTip="MHManager Help (F1)"
                                    MinWidth="20"
                                    MinHeight="20"
                     />
              </Fluent:WindowCommands.Items>
        </Fluent:WindowCommands>
</Fluent:RibbonWindow.WindowCommands>```
