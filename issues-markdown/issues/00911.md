## batzen commented on 2021-03-09T07:28:02Z

That's because the designer is running it's own application and does not provide the resources correctly.
There are ways to solve this in the ribbon library, but most of the parts to get this working during design time are internal to the .NET framework. Will try to solve this but i won't promise to get this fixed soon.

## batzen commented on 2021-03-22T17:30:02Z

I tried a lot of things to get this fixed, but there is no way to fix this as the designer process is not providing information about the current context (project, assembly etc.).
It only works for Image and it's source because there is a type converter which preserves this information during BAML compile time, as far as i found out.
If you want this to work you should report this issue to Microsoft or use a fully qualified "pack" URI (including the assembly).
Sample for fully qualified "pack" URI `pack://application:,,,/Fluent.Ribbon.Showcase;component/Images/Red.png`
