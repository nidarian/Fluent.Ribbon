<h2>[5.3.0] / 2021-08-04</h2>
<ul>

<li>Fixed path construction to be lazy for in-memory solutions that get saved</li>
<li>Fixed <code>GitHubTasks.GetGitHubBrowseUrl</code> to trim trailing slash</li>
<li>Fixed <code>GitVersionAttribute.Framework</code> default value to <code>net5.0</code></li>
<li>Fixed URLs in <code>ChangeLogTasks</code></li>
<li>Fixed <code>DotNetTestSettings.Loggers</code> property to accept multiple values</li>
<li>Fixed default value emission for <code>DotCoverTasks</code></li>
<li>Fixed missing properties for <code>GitVersionTasks</code></li>
<li>Fixed missing secret attributes in <code>SonarScannerTasks</code></li>
<li>Fixed <code>NerdbankGitVersioningFormat</code> enumeration to use lower-case</li>
</ul>
<h2>[5.2.1] / 2021-06-18</h2>
<ul>
<li>Fixed telemetry</li>
<li>Fixed humanized string concatenation</li>
</ul>
<h2>[5.2.0] / 2021-06-18</h2>
<ul>
<li>Added telemetry data collection</li>
<li>Added unified <code>NukeBuild.Partition</code> property</li>
<li>Added <code>Rider</code>, <code>VisualStudio</code>, <code>VSCode</code> as <code>Host</code> implementations</li>
<li>Added <code>GitRepository.IsOnMainBranch</code> and <code>IsOnMainOrMasterBranch</code></li>
<li>Added <code>AbsolutePath</code> equality operators</li>
<li>Fixed SpaceAutomation to generate default <code>refSpec</code></li>
<li>Changed <code>Microsoft.CodeAnalysis.CSharp</code> package version to <code>3.9.0</code></li>
<li>Removed <code>Refit</code> reference and <code>ITeamCityRestClient</code> interface</li>
<li>Removed <code>Colorful.Console</code> reference and embedded figlet fonts</li>
</ul>
