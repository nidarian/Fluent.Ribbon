## batzen commented on 2017-04-20T16:59:37Z

There is no built in way for doing so.
One way to get this working would be to subclass `WindowCommands` and provide your own instance of that to the `RibbonWindow`. In said subclass you could then use code `OnApplyTemplate` to hide the minimize button (part is named `PART_Min`).
The user can still use the contextmenu on the titlebar and other methods to get the window minimized.
