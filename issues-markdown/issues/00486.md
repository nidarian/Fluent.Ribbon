# Issue #486: Stretching of DropDownButton differs from Button

- **State:** closed

I'm making a vertical list of buttons, where I have mixed "Button" and "DropDownButton". I have noticed that the "Button" stretches to the width of my panel, which looks quite ok. The DropDownButton however does not stretch. I have tried to change the Width or HorizontalAlignment, the first seems to enlarge the container but not stretch the control, the second seems to do nothing at all.

I noticed in the styling templates that the property is set differently:

For Button:
`HorizontalAlignment="{TemplateBinding HorizontalAlignment}"`

For DropDownButton:
`HorizontalAlignment="Left"`

This makes it impossible to change the HorizontalAlignment to stretch the control. Wouldn't it be better to do the same for HorizontalAlignment (and VerticalAlignment) as in Button?

Is there any other way to set the HorizontalAlignment?

- Fluent.Ribbon __v5.0.1__
