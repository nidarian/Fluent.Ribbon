## batzen commented on 2016-02-07T20:22:54Z

Hi Peter,

you have to restore the nuget packages and you have to use Visual Studio 2015 to compile the solution.
Visual Studio 2015 should also restore the nuget packages automatically when you compile.

The "$" is new in C# 6 and allows string interpolation.
In the past you had to write string.Format("Value: {0}", value) and with string interpolation you can write $"Value: {value}".
