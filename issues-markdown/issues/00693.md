## batzen commented on 2019-02-10T21:34:19Z

The event is fired at the right time.
The problem you have here is that the bound value, which controls the visual state, is not yet updated.

If you need the updated size values one possible solution would be to listen to `IsMinimizedChanged` and run your size dependent code asynchronous in the current dispatcher.
