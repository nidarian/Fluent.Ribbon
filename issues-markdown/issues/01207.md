## batzen commented on 2024-07-01T16:43:41Z

Setting the size won't work if you are also using a reduce order on the tab/group the control is contained in.
If you want to force a certain size when also using a reduce order you have to use `SizeDefinition="Middle"` for example.
This only applies to controls used in tabs/groups.
