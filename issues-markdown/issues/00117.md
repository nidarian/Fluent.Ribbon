# Issue #117: Backstage not shown when Window Content is not a FrameworkElement

- **State:** closed
- **Author:** janbernloehr
- **Created:** 2015-05-22T19:16:52Z
- **Closed:** 2015-05-29T08:25:48Z
- **Labels:** Bug :lady_beetle:
- **Original:** https://github.com/fluentribbon/Fluent.Ribbon/issues/117

If the Content property of the RibbonWindow is set to an arbitrary .NET object (and a DataTemplate is defined to display this object properly), the Backstage is not shown when the RibbonMenuButton is clicked. Instead an InvalidCastException is thrown as the Backstage code assumes that the Content property is always a FrameworkElement.
