We have issues with backwards compatibility with plugins that use Fluent 6.x, but we have upgraded our shell to Fluent 7.x.

The first thing that happened was that there were issues with `ThemeManager.` We solved them by explicitly adding the version to the xaml loading:

```
                var assembly = typeof(ThemeManager).Assembly;
                var name = assembly.GetName();
                var assemblyName = name.Name;
                var assemblyVersion = name.Version;
                var resourceNames = assembly.GetManifestResourceNames();

                ...

                           var resourceDictionary = new ResourceDictionary
                            {
                                Source = new Uri($"pack://application:,,,/{assemblyName};v{assemblyVersion};component/{stringKey.Replace(".baml", ".xaml")}")
                            };
```

This seems to fix *part of* the problem. Will continue to do more research and hopefully provide a PR with some fixes.
