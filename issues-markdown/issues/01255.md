## batzen commented on 2025-12-19T13:29:57Z

As the error message states: You have to use a `Brush`, in this case most likely a `SolidColorBrush` instead of a `Color`.
The resource name also contains the type hint "Brushes" as opposed to "Colors" for the other resources.
