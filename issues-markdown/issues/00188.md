# Issue #188: How to remove the area in front of MenuItems (SplitButton)?

- **State:** closed
- **Author:** wstaelens
- **Created:** 2015-10-26T14:11:18Z
- **Closed:** 2015-10-29T11:48:53Z
- **Labels:** Question :question:
- **Original:** https://github.com/fluentribbon/Fluent.Ribbon/issues/188

``` xml
<Fluent:SplitButton Header="Foo" ItemsSource="{Binding FooData}">
          <Fluent:SplitButton.LargeIcon>
            <Rectangle Fill="{StaticResource imgFoo"} />
          </Fluent:SplitButton.LargeIcon>
          <Fluent:SplitButton.ItemTemplate>
            <DataTemplate>
              <Fluent:MenuItem Header="{Binding Title}">
                <Fluent:MenuItem.Icon>
                  <Rectangle Fill="{StaticResource imgFoo2}" Stretch="Uniform" />
                </Fluent:MenuItem.Icon>
              </Fluent:MenuItem>
            </DataTemplate>
          </Fluent:SplitButton.ItemTemplate>
        </Fluent:SplitButton>
```

You will see that each MenuItem has a space in front of the item. How can this space be removed?
I thought it was for some checkbox but "IsChecked" property on MenuItem does not remove the space.

Using a Gallery on a DropDownButton doesn't have this extra space in front of the MenuItems:

``` xml

        <Fluent:DropDownButton Header="Bar">
          <Fluent:DropDownButton.LargeIcon>
            <Rectangle Fill="{StaticResource imgBar}" />
          </Fluent:DropDownButton.LargeIcon>
          <Fluent:Gallery ItemsSource="{Binding BarData}">
            <Fluent:Gallery.ItemTemplate>
              <DataTemplate>
                <Fluent:MenuItem Header="{Binding Title}">
                  <Fluent:MenuItem.Icon>
                    <Rectangle Fill="{StaticResource imgBar2}" Stretch="Uniform" />
                  </Fluent:MenuItem.Icon>
                </Fluent:MenuItem>
              </DataTemplate>
            </Fluent:Gallery.ItemTemplate>
          </Fluent:Gallery>
        </Fluent:DropDownButton>`
```

Is it a "style bug" that is forgotten? or do you always need to use a Gallery for SplitButton?
I could not find it in a manual or documentation.

## batzen commented on 2015-10-26T17:38:23Z

It's the age old problem with ItemsControl, ItemsSource and DataTemplates.
If you want to get rid of that space you will have to use ItemContainerStyle.
Please see: http://stackoverflow.com/questions/1312895/using-a-datatemplate-for-a-menuitem-causes-extra-space-on-the-left-side-to-appea
