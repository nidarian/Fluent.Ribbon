# Issue #813: Add option to disable auto focus of the first menu item.

- **State:** open
- **Author:** TomNere
- **Created:** 2020-06-02T09:23:24Z
- **Closed:** -
- **Labels:** Feature :1st_place_medal:
- **Original:** https://github.com/fluentribbon/Fluent.Ribbon/issues/813

When the menu is opened, the first item is Focused and has MouseOver style. This can be a little confusing for the user.
So, it would be great to have some property in DropDownButton and SplitButton which deactivates auto focus of the first menu item.
