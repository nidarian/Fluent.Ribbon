# Issue #842: Prevent minimizing the window while retaining the ability to resize & maximize?

I have been looking into ways to hide or disable the ability to minimize a RibbonWindow. In my application, this window is a modal child of the main application, so minimizing only this window would not make sense. However, I do need to retain the ability to resize and maximize / restore it.

I read a partial solution in another post:
https://github.com/fluentribbon/Fluent.Ribbon/issues/426#issuecomment-295814358

but that approach would allow the window's context menu to still be active.

I've also tried out using Win32 calls (based on https://stackoverflow.com/a/958980/3195477) which does not work, I think because the RibbonWindow title bar is not the Win32 window's title bar.

Are there any other options I should consider? 

 * For example, if I changed from using RibbonWindow to a standard Window, what are the consequences (if this is described elsewhere I apologize that I haven't found it yet).

 * Or, perhaps, is there a way to control the contents of the RibbonWindow context menu?

Thanks!

## batzen commented on 2020-09-06T07:43:54Z

There is currently no way to prevent only minimizing out of the box.
You could set `EnableMinimize` to `false` on the `WindowChromeBehavior` (which is attached to `RibbonWindow`) and grab `PART_Min` from `WindowCommands` to set its visibility.
