Hello.

I am trying to use Fluent Ribbon, but it does not work in my way.
Nothing appeared in the preview window in Visual Studio.
After executed, black window appeared.

![Uploading FluentBlackWindow.png…]()

What I did are:
1. Create WPF application by Visual Stuido 2013 Professional
2. Get Fluent Ribbon Control Suite 3.4.0 via NuGet
3. Add the <ResourceDictionay> tab to App.xaml

```
<Application x:Class="FluentRibbon.App"
             xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             StartupUri="MainWindow.xaml">
    <Application.Resources>
        <!--Attach Default Fluent Control's Theme-->
        <ResourceDictionary Source="pack://application:,,,/Fluent;Component/Themes/Office2010/Silver.xaml" />
    </Application.Resources>
</Application>
```
1. Change parent class: Window -> Fluent.RibbonWindow

```
namespace FluentRibbon
{
    /// <summary>
    /// MainWindow.xaml の相互作用ロジック
    /// </summary>
    public partial class MainWindow : Fluent.RibbonWindow
    {
        public MainWindow()
        {
            InitializeComponent();
        }
    }
}
```
1.  Add `xmlns:Fluent="clr-namespace:Fluent;assembly=Fluent"` and <Fluent> tags to MainWindow.xaml

```
<Fluent:RibbonWindow x:Class="FluentRibbon.MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        xmlns:Fluent="clr-namespace:Fluent;assembly=Fluent"
        Title="MainWindow" Height="350" Width="525">
    <Grid>
        <Fluent:Ribbon>
            <!--Backstage-->
            <Fluent:Ribbon.Menu>
                <Fluent:Backstage>
                </Fluent:Backstage>
            </Fluent:Ribbon.Menu>
            <!--Tabs-->
            <Fluent:RibbonTabItem Header="Tab">
                <Fluent:RibbonGroupBox Header="Group">
                    <Fluent:Button Name="buttonGreen" Header="Green" Icon="Images\new.png" LargeIcon="Images\new.png" />
                    <Fluent:Button Name="buttonGray" Header="Grey" Icon="Images\new.png" LargeIcon="Images\new.png" />
                </Fluent:RibbonGroupBox>
            </Fluent:RibbonTabItem>
        </Fluent:Ribbon>
    </Grid>
</Fluent:RibbonWindow>
```

Please help me.

## chdft commented on 2015-05-13T10:43:59Z

I think you forgot to merge the theme specific resources with the generic ones. Try this:

``` xaml
<Application.Resources>
    <ResourceDictionary>
        <ResourceDictionary.MergedDictionaries>
            <!--Attach Default Fluent Control's Theme-->
            <ResourceDictionary Source="pack://application:,,,/Fluent;Component/Themes/Generic.xaml" />
            <ResourceDictionary Source="pack://application:,,,/Fluent;Component/Themes/Office2010/Silver.xaml" />
        </ResourceDictionary.MergedDictionaries>
    </ResourceDictionary>
</Application.Resources>
```

## pekspro commented on 2015-05-14T07:11:49Z

I have had exactly the same problem. My problem was that I used this path:

```
LargeIcon="document.png"
```

The correct path is:

```
LargeIcon="pack://application:,,,/YourAssemblyName;component/document.png"
```
