The gallery item is not visible when clicked with the mouse when Fluent.Ribbon.Brushes.GalleryItem.Pressed is defined as opaque color. Only the border with the pressed color is shown instead. 

This is because the pressedBorder Border is defined after the ContentPresenter in the GalleryItem control template and will therefore overlay the content of the item.

I'm using Fluent.Ribbon v7.1.0.
