## batzen commented on 2019-04-16T16:13:05Z

The default for `IsEditable` in Fluent.Ribbon is `true`.
That decision, using `true` as the default, was made before i took over this project in 2012 and i never wanted to break the existing usages.
If you use `IsEditable="False"` on the `ComboBox` everything is fine.
