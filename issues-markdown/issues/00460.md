Clipboard ApplicationCommands like Cut, Copy and Paste don't work as command value in buttons, because they don't get activated. This behaviour occurs from Fluent.Ribbon Version 3.0.0 on but buttons become activated in the old version 2.0.2.
For example:

```xaml
<Fluent:RibbonWindow x:Class="WpfApplication10.Test07ApplicationCommandsFluent"
                     xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
                     xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
                     xmlns:d="http://schemas.microsoft.com/expression/blend/2008"
                     xmlns:mc="http://schemas.openxmlformats.org/markup-compatibility/2006"
                     xmlns:Fluent="clr-namespace:Fluent;assembly=Fluent"
                     mc:Ignorable="d"
                     Title="Test07ApplicationCommandsFluent" Height="300" Width="300">
    <Grid>
        <Grid.RowDefinitions>
            <RowDefinition Height="Auto"/>
            <RowDefinition Height="37*"/>
            <RowDefinition Height="232*"/>
        </Grid.RowDefinitions>
        <Fluent:Ribbon Grid.Row="0">
            <Fluent:RibbonTabItem Fluent:KeyTip.Keys="A" Header="Allgemein" ReduceOrder="Clipboard,Clipboard,Clipboard">
                <Fluent:RibbonGroupBox x:Name="Clipboard" Header="Zwischenablage" Icon="{StaticResource bmpPaste}">
                    <Fluent:Button x:Name="fbtPaste"  Command="ApplicationCommands.Paste" Size="Large" Header="Paste"  LargeIcon="{StaticResource bmpPasteLarge}" Icon="{StaticResource bmpPaste}" IsEnabled="True"/>
                    <Fluent:Button x:Name="fbtCut" Command="ApplicationCommands.Cut"  Size="Small" Header="Cut" Icon="{StaticResource bmpCut}"/>
                    <Fluent:Button x:Name="fbtCopy" Command="ApplicationCommands.Copy" Size="Small" Header="Copy" Icon="{StaticResource bmpCopy}"/>
                </Fluent:RibbonGroupBox>
            </Fluent:RibbonTabItem>
        </Fluent:Ribbon>
        <StackPanel  Grid.Row="1">
            <ToolBar>
                <Button Content="Cut" Command="ApplicationCommands.Cut" Height="23" Width="75"/>
                <Button Content="Copy" Command="ApplicationCommands.Copy" Height="23" Width="75"/>
                <Button Content="Paste" Command="ApplicationCommands.Paste" Height="23" Width="75"/>
            </ToolBar>
        </StackPanel>
        <TextBox Grid.Row="2" x:Name="textBox" TextWrapping="Wrap" Text="TextBox" />
    </Grid>
</Fluent:RibbonWindow>
```
---
After selecting text in the TextBox control the cut and copy buttons in the ribbon should become activated like the buttons in the ToolBar.

Yours Macus

Example Project with the upper source code: [WpfApplication11.zip](https://github.com/fluentribbon/Fluent.Ribbon/files/1234875/WpfApplication11.zip)
### Environment

- Fluent.Ribbon 5.0.2.46
- Windows 10.1703
- .NET Framework 4.5.2

## batzen commented on 2017-08-18T16:34:22Z

Please have a look at the breaking changes section of https://github.com/fluentribbon/Fluent.Ribbon/blob/develop/Changelog.md#300 or at https://github.com/fluentribbon/Fluent.Ribbon/issues/54.

You just have to set IsFocusScope=True on buttons using those commands.
