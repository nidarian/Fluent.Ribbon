It's a resource problem, I put the following code in the MainWindow's Window.Resources, Now my program run normally.

    <Window.Resources>
        <!-- Attach default Theme -->
        <ResourceDictionary Source="pack://application:,,,/Fluent;Component/Themes/Generic.xaml" />
    </Window.Resources>
