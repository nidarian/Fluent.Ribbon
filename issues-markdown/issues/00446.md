# Issue #446: Wrong submenu Position in application menu

- **State:** closed

- **Created:** 2017-06-19T05:52:40Z
- **Closed:** 2017-07-04T17:36:14Z
- **Labels:** Bug :lady_beetle:, Styles

If you use an application menu with a large number of menu items and then open a submenu, it opens at a wrong position (moved down).

Steps to reproduce:
- Open the showcase solution
- Add ten more menuitems at the end of the applicationmenu
- Start the showcase application
- Switch to the application menu (not backstage)
- Open the application menu (Click on "File")
- Open the submenu under "New" or "Save As"
- the submenu opens at a wrong position (moved down)


---
### Environment

- Fluent.Ribbon __v5.0.1__
- Windows __10__
- .NET Framework __4.0__
