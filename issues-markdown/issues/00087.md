## batzen commented on 2015-04-16T12:13:16Z

You got a few mistakes here:
- Your XAML file says it's a "Window" whereas your code behind file says it's a "RibbonWindow"
- You are using the namespace "System.Windows.Controls.Ribbon" in code behind, but the fluent components live in "Fluent"

You got two choices now:
- Remove the inheritance from "RibbonWindow" in your code behind file if you wish to use a regular WPF window
- Change your XAML file from using "<Window" to "<fluent:RibbonWindow" if you wish to use our RibbonWindow
