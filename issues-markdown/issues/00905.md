## pisc-software commented on 2021-03-22T17:32:12Z

Thanks for the reply.

For the binding issue that is what I did debug so far:

It seems in my implementation that the DataContext does not propagate to "Ribbon.ContextualGroups". Setting the DataContext for the UserControl (in my case) does work for the UserControl, but it does not propagate to the Contextual Group.
When extending a control class from the "RibbonContextualTabGroup" class and inspecting the DataContext in the constructor the DataContext set for the UserControl (or the Ribbon, or even the RibbonContextualTabGroup in XAML) is not there.

```
    <UserControl.DataContext>
        <vm:MainViewModel />
    </UserControl.DataContext>

```
```
            <control:RibbonContextualTabGroup Header="Some Header" x:Name="contextGroup"
              Visibility="{Binding TabSelectedItem.IsContext, Converter={StaticResource booleanToVisibilityConverter}}"
            >
                <control:RibbonContextualTabGroup.DataContext>
                    <vm:MainViewModel />
                </control:FluentRibbonContextualTabGroup.DataContext>
            </control:FluentRibbonContextualTabGroup>

```

So as workaround the DataContext needs to be set in the child control class and use the child control class in the XAML:

```
    public class FluentRibbonContextualTabGroup : Fluent.RibbonContextualTabGroup
    {
        public FluentRibbonContextualTabGroup() : base()
        {
            this.DataContext = App.Current.Services.GetRequiredService<MainViewModel>();
        }
```
Doing that makes the bindings work. In my case that workaround is so far workable, as also additional attached properties are used for the ContextualTab for visual control.

My use case uses IoC from the Community Toolkit MVVM.
Any thoughts on this?

## batzen commented on 2021-03-22T17:38:46Z

The `DataContext` is not yet set when the object is constructed in WPF, so it's normal that when you debug it's null at that point in time.

As i said in my previous response you could set the datacontext for your `RibbonTitleBar` as i did in the showcase application.
Like this:
```
    <Metro:MetroWindow.TitleTemplate>
        <DataTemplate>
            <Fluent:RibbonTitleBar x:Name="RibbonTitleBar"                                   
                                   Header="{Binding Path=Title, RelativeSource={RelativeSource AncestorType=Window}}"
                                   DataContext="{Binding ElementName=YOUR_ELEMENT_NAME, Path=DataContext}" />
        </DataTemplate>
    </Metro:MetroWindow.TitleTemplate>
```
