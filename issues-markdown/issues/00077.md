## batzen commented on 2015-03-04T20:58:38Z

It's larger because:
- When you open the backstage the window size is increase because there is a minimum window size required by the backstage (500x400 to be exact)
- When you close the backstage the original window size is restored
- But: Restoring/Changing the window size while the window is maximized has no effect on the normal window size
  That's the simple reason why the window is larger than before.
