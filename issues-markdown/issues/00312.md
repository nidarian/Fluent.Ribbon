---

## batzen commented on 2016-04-26T18:28:06Z

The quickaccessbar should only be displayed below the ribbon if you have set `ShowQuickAccessToolBarAboveRibbon="False"` or you moved it below manually, closed your window and have `AutomaticStateManagement="True"`.

The default value for both mentioned options is `True`. So it should be displayed above the ribbon by default.

## batzen commented on 2016-04-26T18:41:07Z

ShowQuickAccessToolBarAboveRibbon is ignored if you moved it below and never up again manually. That's because user state is handled after everything else is setup.
