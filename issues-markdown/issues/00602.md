# Issue #602: Pin button not clickable when Ribbon in collapsed state

- **State:** closed
- **Author:** rhostudios
- **Created:** 2018-08-05T08:56:11Z
- **Closed:** 2018-08-05T15:52:45Z
- **Labels:** Bug :lady_beetle:
- **Original:** https://github.com/fluentribbon/Fluent.Ribbon/issues/602

**Issue:**
Problem with pin button for pinning ribbon when in collapsed state.

**Expected behaviour:**
Pin button should be clickable, and ribbon should be pinned after clicking the pin button.

**Encountered behaviour:**
Pin button is not clickable. Shortcut (Ctrl + F1) still works.

**Recreating issue:**
1. Create a new project and add the ribbon with one or more menu items.
2. Collapse the ribbon using the collapse button or shortcut.
3. Click on a menu item to display the ribbon so that the collapse button changes to a pin.
4. Pin button is displayed, but not clickable.

**Other notes:**
As mentioned, shortcut (Ctrl + F1) still works.
There is no code behind for the Window except the initialisation component.

---
### Environment

- Fluent.Ribbon 6.1.0.326
- Windows 10 Enterprise
- .NET Framework 4.7.2
