# Issue #664: SplitButton.IsChecked deleting binding upon click.

- **State:** closed
- **Author:** DynamicField
- **Created:** 2018-11-13T20:45:01Z
- **Closed:** 2018-11-13T21:11:14Z
- **Labels:** -
- **Original:** https://github.com/fluentribbon/Fluent.Ribbon/issues/664

When `SplitButton.IsChecked` is bound, the binding works correctly until the button is clicked, the binding gets deleted and is then no longer updated (to the viewmodel for example).

Example where the problem happens:

```<fluent:SplitButton IsCheckable="True" IsChecked="{Binding IsButtonChecked, Mode=OneWay}"/>```

---
### Environment

- Fluent.Ribbon __v7.0.0-alpha0456__
- Windows __10__
- .NET Framework __4.5.2__
