## batzen commented on 2019-09-28T16:05:36Z

You can just add items to `WindowCommands`.
Any item added to that control is shown before the real window commands.

For example:
```xaml
    <Fluent:RibbonWindow.WindowCommands>
        <Fluent:WindowCommands>
            <Button Content="Test" Foreground="{DynamicResource Fluent.Ribbon.Brushes.LabelTextBrush}" />
        </Fluent:WindowCommands>
    </Fluent:RibbonWindow.WindowCommands>
```
