## batzen commented on 2016-11-22T18:02:04Z

That's true and won't be possible.
The reason is that `Header` is of type object, so you can place whatever you want in it.
The binding engine in WPF is responsible for applying `StringFormat` on bindings. To be able to do this there is a type check for the corresponding `DependencyProperty`. If the `DependencyProperty` is of type `string` the `StringFormat` is used. If it's not of type `string` the `StringFormat` is ignored completely.
See https://referencesource.microsoft.com/#PresentationFramework/src/Framework/System/Windows/Data/BindingExpressionBase.cs,7447fc99cc85c66b,references
