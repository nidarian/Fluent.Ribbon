## chdft commented on 2015-05-04T10:54:35Z

You can change the global theme color using the code snippet below (replace #000000 with your theme color). That changes the color of status bars, backstages, etc.

``` xaml
<Color x:Key="{x:Static Fluent:MetroColors.ThemeColorKey}">#000000</Color>
```

To make it apply globally, you have to merge it with the theme you use (Office2013/Generic.xaml in your case). That will look like this (in App.xaml):

``` xaml
<ResourceDictionary.MergedDictionaries>
    <!--Attach Default Fluent Control's Theme-->
    <ResourceDictionary Source="pack://application:,,,/Fluent;Component/Themes/Generic.xaml" />
    <ResourceDictionary Source="pack://application:,,,/Fluent;Component/Themes/Office2013/Generic.xaml" />
    <ResourceDictionary Source="Design.xaml" /> <!-- this contains your changes to the Fluent theme -->
</ResourceDictionary.MergedDictionaries>
```

I don't know if this is the intended way, but it works and I've not seen any side effects.

## batzen commented on 2015-05-04T17:43:44Z

To sum this up:
- To change the background of the StatusBar you currently have to modify the RibbonThemeColorBrush. This could be made easier on our side by setting this background on the Style level rather than the inner border or the control.
- Just changing the Background property on the RibbonTabItem wouldn't help much as you got many colors which are used there. Think of states like "Selected", "Hover" etc. those could, of course, all be exposed but there is nothing planned to implement it in that way. If you want to, feel free to open a new issue and discuss the details of such a change.
- To change the foreground: there is a "DefaultFontBrush" which you could change and see how far you can go with that. Duo to the history of this library, on one side, this was needed in the past. I can image that we could eliminate that one mostly. But we have to set some foreground color somewhere (maybe at the ribbon level) and as I don't need it that way (I can live with the current implementation) I won't change it. On the other side we got many different background colors and so we need different foreground colors. An easy way to be able to find foreground colors is to search for "FontBrush" and see which ones you need to change according to your requirements.
