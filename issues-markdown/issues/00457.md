# Issue #457: Using the keytip shortcut to open a backstage briefly opens it, then closes it immediately

- **State:** closed
- **Author:** niratch
- **Created:** 2017-08-16T02:29:03Z
- **Closed:** 2017-08-16T16:26:23Z
- **Labels:** Bug :lady_beetle:, Breaking Change :fearful:
- **Original:** https://github.com/fluentribbon/Fluent.Ribbon/issues/457

To repro this issue, you can use the Fluent.Ribbon.Showcase project. The only change that needs to be made to that project is to go into the Backstage XAML and remove all KeyTips on all BackstageTabItems. Then, start up the application and use (Alt + F) to open up the backstage -- you will see that it immediately closes.

This issue seems to have been introduced by this [change]( https://github.com/fluentribbon/Fluent.Ribbon/commit/9b5d5d5104a4b0f9accddb45fcbad543ff38f268). In particular, `OnAdornerChainTerminated` now calls `ClosePopups`, raising the `DismissPopupEvent`, which the backstage control has subscribed to. Upon receival of this event, the backstage closes itself. This event is not fired if the adorner chain is not terminated, for example, because the backstage itself has children with keytips.
