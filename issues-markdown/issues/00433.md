# Issue #433: ToggleButton not working correctly when placed in collapsed GroupBox

- **State:** closed
- **Author:** h3rr-d
- **Created:** 2017-05-11T10:54:19Z
- **Closed:** 2017-05-11T18:56:49Z

- **Original:** https://github.com/fluentribbon/Fluent.Ribbon/issues/433

Assume you have 2 GroupBoxes with a bunch of ToggleButtons. All Buttons are in the same "toggle"-group.
Selecting one of the buttons will uncheck all the others.

If you set the state of one GroupBox to "collapsed" this does not work anymore.
You can toggle two buttons although all button are still in the same "toggle"-group

---
### Environment

- Fluent.Ribbon __5.0.1.10__
- Theme __?__ (not needed in version 5.0 and upwards)
- Windows __10 Professional__
- .NET Framework __4.6__
