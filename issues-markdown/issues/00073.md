When changed to this component i couldn't find a way to recover the vertical space, currently I am keeping the ribbon minimized and added the following in the ribbon styles:

var titleBarStyle = new Style(typeof (RibbonTitleBar));
titleBarStyle.Setters.Add(new Setter(UIElement.VisibilityProperty, Visibility.Hidden));
item.Resources.Add("RibbonTitleBarStyle", titleBarStyle);
var quickAccessStyle = new Style(typeof (QuickAccessToolBar));
quickAccessStyle.Setters.Add(new Setter(UIElement.VisibilityProperty, Visibility.Hidden));
item.Resources.Add("QuickAccessToolbarStyle ", quickAccessStyle);

To hide the Title, because the form title doesn't really represent the title it must show, and I believe the component is bound to the containing form title.

Long story short: I use the ribbon as a rich menu, but want the most of the vertical space I can provide my users.

## pekspro commented on 2015-03-04T17:09:39Z

I have made a fork of the Fluent Ribbon, where I have added an option to use the default window frame. You find it here:

https://github.com/pekspro/Fluent.Ribbon

If you add UseDefaultWindowsChrome="True" as an attribute to the windows the default frame will be used. If you also add WindowStyle="None" the title bar will be removed.

I’m not sure that is exactly what you are looking for. Also note than when you do this some other elements that are in the title bar will be removed (like contextual ribbons etc).

## pekspro commented on 2015-03-08T17:40:39Z

As suggested above a changed my application to the use original Windows class instead of FluentWindow. I also added Fluent:RibbonProperties.TitleBarHeight="0" to remove the title bar and added IsQuickAccessToolBarVisible="False" to hide the quick access toolbar (which still was accessible with the tab key).

And it works perfectly! I no longer need my fork – Thanks! Yeah! :-)

## cosijuan commented on 2016-04-08T16:18:38Z

In the Load event of the window, add the next line:

((System.Windows.UIElement)((System.Windows.FrameworkElement)(this.RibbonMain.Template.FindName("PART_TitleHost", this.RibbonMain) as ContentPresenter).Parent).Parent).Visibility = Visibility.Collapsed;
