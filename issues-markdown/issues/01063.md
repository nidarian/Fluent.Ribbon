## batzen commented on 2022-09-05T14:23:46Z

There is currently no built in watermark support in Fluent.Ribbon.
If you need such a feature now you can either use MahApps.Metro and re-style/re-template the TextBox from Fluent.Ribbon or build your own watermark code/triggers and re-style/re-template the TextBox from Fluent.Ribbon.
The template for the TextBox is "only" 81 lines, so it's not that much.
If you decide to re-template you have to keep an eye on the original template in case of updates.

I might add built in watermark support in a later version of Fluent.Ribbon.

May i ask where you got the links from?
The only documentation root that exists is at https://fluentribbon.github.io/documentation/ and there are no 404 links on there.
