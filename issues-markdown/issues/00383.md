## batzen commented on 2016-12-23T22:03:52Z

Ok, now i see your issue.

You can't simply set Template of QuickAccessMenuItem to a control containing multiple QuickAccessMenuItem to get some kind of dynamic menu, that's just not the way WPF works in general.

If you want to get a dynamic menu you should use some kind of factory to inject QuickAccessMenuItem instances into Ribbon:QuickAccessMenuItems.
