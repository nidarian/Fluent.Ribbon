# Issue #556: Wrong Window Resize-Border Sensitivity

- **State:** closed
- **Author:** atlastodor
- **Created:** 2018-04-04T10:07:18Z
- **Closed:** 2018-07-07T13:54:43Z
- **Labels:** WindowChrome
- **Original:** https://github.com/fluentribbon/Fluent.Ribbon/issues/556

The sensitivity of the window's resize border is wrong (too small) on some parts of the window. The illustration below shows a test window and the resize border. The places marked with red, the resize border sensitivity is only 1-2 pixels wide (difficult to grab with the mouse) while the remaining part (in green) the sensitivity is wider and easy to use.

![image](https://user-images.githubusercontent.com/22751987/38300375-e27780ca-37fc-11e8-991e-6f6eb3d8797e.png)

Some debugging showed that the issue may be a combination between ControlzEx WindowChomreWorker._HandleNCHitTest() and the WindowChrome.IsHitTestVisibleInChrome property. The Ribbon has the property and this makes it HT_CLIENT instead of resize border. I am not sure if this is a Fluent issue or ControlzEx issue. Removing if from the Ribbon makes the border wider, but may have side effects. Also, this does only fixes part of the problem, because the RibbonTitleBar and other controls have the same issue.

---
### Environment

- Fluent.Ribbon 6.1.0
- Windows 10
- .NET Framework 4.6.2

## atlastodor commented on 2018-08-22T08:45:29Z

Hi Bastian,

I have updated our app to v7.0.0-alpha0388 and ControlzEx to v4.0.0-alpha0161. I can confirm that the border issue is gone.

I must mention that there is a side-effect of the new implementation. The border is drawn as part of the window's client area. This means that the app and the app's UI thread is responsible for this task. If the app is complex (layouting takes some time) and the user resizes vigorously, it is visible that the app lacks a little behind before updating the window. This was not the case with the native non-client implementation. However, both Visual Studio and MS Office apps exhibit this behavior - so I guess we will have to live with it.

Thanks for the help.
