## batzen commented on 2020-08-15T13:41:07Z

That's by design as you are using a regular window instead of a `RibbonWindow`.
When you don't use a `RibbonWindow` the quick access toolbar is not present.
If you don't want to use `RibbonWindow` the only way to show a quick access toolbar above the ribbon is to set `TitleBar` on the `Ribbon` to some `RibbonTitleBar`.
