## batzen commented on 2016-11-21T19:11:03Z

The button is inside the `BackstageTabControl` and it's name is `backbutton`.
The is no implemented way to hide it.

But depending on what you are trying to achieve it might be better to use the `StartScreen` instead of `Backstage`.
`StartScreen` and `StartScreenTabControl` have no back-button by default.
