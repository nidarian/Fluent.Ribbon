## dngs365 commented on 2018-04-01T15:02:06Z

And here is my temporary fix.
    
    using System;
    using System.Reflection;
    using System.Windows.Controls;
    using System.Windows.Controls.Primitives;

    public class Spinner : Fluent.Spinner
    {
        static readonly FieldInfo textBoxField = typeof(Fluent.Spinner).GetField("textBox", BindingFlags.NonPublic | BindingFlags.Instance);

        public override void OnApplyTemplate()
        {
            base.OnApplyTemplate();
            if (null != textBoxField && textBoxField.GetValue(this) is TextBox tb)
            {
                tb.SetResourceReference(TextBoxBase.CaretBrushProperty, "TextBrush");
                tb.SetResourceReference(TextBoxBase.SelectionBrushProperty, "SelectedBrush");
            }
        }
    }

## batzen commented on 2018-04-02T19:14:02Z

So i had a look at this and the caret brush is white when the theme is dark. 
I think that's the best color for readability. 

I'm unsure about the selection brush.

Which colors would you suggest instead?

You can't simply change the colors. The brushes using those colors use them as `StaticResource` and are frozen because they have to be usable from windows in different dispatcher threads.
If you want to change to colors you have to provide a complete resource dictionary overwriting the colors and overwriting the brushes.
All brushes and colors are used as `DynamicResource` inside the control styles.
