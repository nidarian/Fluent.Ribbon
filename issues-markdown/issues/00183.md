## batzen commented on 2015-10-22T13:18:42Z

```
<Ribbon.Resources>
    <Style TargetType="{x:Type Label}"
               BasedOn="{StaticResource {x:Type Label}}" />
</Ribbon.Resources>
```

Should do the job and reset the label style back to the default one only for the ribbon.
