Hi

I am using the Fluent Ribbon for longer and I used this XAML pattern to extend the theme for a `RibbonBackstageTabItem`:

```xml
<Style TargetType="TabItem" x:Key="RibbonBackstageTabItem" BasedOn="{StaticResource InnerBackstageTabControlItem}">
	<Setter Property="Foreground" Value="{DynamicResource {x:Static SystemColors.ActiveCaptionTextBrushKey}}"/>
	<Style.Triggers>
		<Trigger Property="IsSelected" Value="True">
			<Setter Property="Foreground" Value="White"/>
		</Trigger>
	</Style.Triggers>
</Style>
```

It worked very well but out of the blue VS tells me that the ressource `InnerBackstageTabControlItem` cannot be resolved and the whole Designer ignores everything related to the Ribbon ... I tried to restart everything, to reinstall the nuget package and to look for it by myself but I cannot open the currently downloadable version ... maybe you use a newer version of VS as I do (2015 Express).

It would be great if you had any idea on what happend since I didn't even update the nuget package when the error occured (I did it after that but it obiously did not fix it -.-')


Many thanks
the-madcat
