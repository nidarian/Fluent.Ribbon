I am using a user control to place the ribbon using a ContentPresenter via my main WPF window. Everything seems to be perfectly working except when clicking a ribbon menu button from the backstage, it does not slide off automatically.

When I place the ribbon directly on the main window everything works fine as usual. How to fix this issue please. Thanks

## batzen commented on 2019-01-12T21:26:48Z

Not sure this is a bug in Fluent.Ribbon or something in WPF that is either buggy or works as designed.
Just change `ContentPresenter` to `ContentControl` in your window and it works.
