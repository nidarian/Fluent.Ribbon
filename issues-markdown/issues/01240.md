Say, I have some command:
```csharp
public static class CustomCommands
{
  private static readonly RoutedUICommand runQueryCommand;
  static CustomCommands()
  {
    runQueryCommand = new(text: "Run Query", name: "RunQuery", ownerType: typeof(CustomCommands));
  }
  public static RoutedUICommand RunQueryCommand => runQueryCommand;
}
```
Key bindings:
```xaml
<r:RibbonWindow.InputBindings>
  <KeyBinding Modifiers="Ctrl" Key="R" Command="local:CustomCommands.RunQueryCommand"/>
</r:RibbonWindow.InputBindings>
```
When I start app and immediately press Ctrl+R, nothing in UI happens. However, if I press some Ribbon button AND THEN press Ctrl+R, then this button gets selected. In other words, last control gets selected.

## batzen commented on 2025-04-04T08:42:47Z

You can set the FocusVisualStyle to null.
But that will remove it for every case, including keyboard navigation.
And you would either have to set that style to null for various control types and it might not work for every control as some controls use style/template triggers instead to visualize keyboard focus.
