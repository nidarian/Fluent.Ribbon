## batzen commented on 2023-06-14T10:51:20Z

I don't think adding a single CornerRadius to all controls is a good idea.
Back in the Office 2010 days the styling in Fluent.Ribbon also was more rounded and that wasn't solvable by a single property and required lots of different stylings/borders/rectangles to get everything right.

If we want to add rounding it should be solved by introducing new resources for everything that should be rounded, but i am not yet sure if i want to open that pandoras box again.
