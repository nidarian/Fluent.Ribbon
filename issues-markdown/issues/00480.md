# Issue #480: Disable Scroll Wheel for tab selection

I run Windows in a VM on a MacBook.  I use the Apple Magic Mouse.  This mouse uses a touch surface for the scroll wheel, which makes it very easy to accidentally trigger scroll events.  When using the Fluent.Ribbon it has happened many times where the tab I'm looking at suddenly changes because of this.

So I would like to request a mechanism by which the tab selection via scroll wheel can be disabled.  Perhaps a property on the Ribbon control?
