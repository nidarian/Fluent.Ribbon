I'm having troubles getting my application to startup with the ribbon minimized.

                       DockPanel.Dock="Top" CanCustomizeQuickAccessToolBarItems="False" 
                       IsQuickAccessToolBarVisible="False" 
                       ShowQuickAccessToolBarAboveRibbon="False" 
                       IsMinimized="True" >

When my application startup the ribbon is not minimized?

## batzen commented on 2015-10-21T17:27:31Z

That's because of `AutomaticStateManagement` being true by default.
AutomaticStateManagement controls whether the last state should be saved to disk and loaded when the window is loaded.
If you minimize the ribbon, close the window/application and reopen it, the ribbon should be minimized.

## batzen commented on 2015-10-27T17:43:08Z

It's possible. Just set IsMinimized=true.
When your user starts the application for the first time the ribbon should be minimized.
It's just that the AutomaticStatemanagement saves the last property state to disk and loads it from there. So if your user restored the ribbon it shows restored on the next start.
