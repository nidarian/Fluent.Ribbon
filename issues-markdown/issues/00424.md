When using the Fluent Ribbon, I'm getting a stream of missing resources in the debug output window.  The resources exist in the 'Generic.xaml', and I'm otherwise picking up the styles, but for some reason the controls are not finding the resources.
At the start of my module I have:
`<dbcontrols:FrameViewBase x:Class="DarkBond.LicenseManager.Views.FrameView"
						  xmlns:Fluent="clr-namespace:Fluent;assembly=Fluent"
						  xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
						  xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation">
	<dbcontrols:FrameViewBase.Resources>
		<ResourceDictionary>
			<ResourceDictionary.MergedDictionaries>
				<ResourceDictionary Source="/DarkBond.LicenseManager.Views;Component/Themes/theme.xaml"/>
				<ResourceDictionary Source="/Fluent;Component/Themes/Generic.xaml"/>
			</ResourceDictionary.MergedDictionaries>
`
The debug window outputs a continuous stream of as I change the data context of the ribbon:
`System.Windows.ResourceDictionary Warning: 9 : Resource not found; ResourceKey='RibbonButtonControlTemplate'
System.Windows.ResourceDictionary Warning: 9 : Resource not found; ResourceKey='TwoLineLabelControlTemplate'
System.Windows.ResourceDictionary Warning: 9 : Resource not found; ResourceKey='TwoLineLabelControlTemplate'
System.Windows.ResourceDictionary Warning: 9 : Resource not found; ResourceKey='TwoLineLabelControlTemplate'
System.Windows.ResourceDictionary Warning: 9 : Resource not found; ResourceKey='TwoLineLabelControlTemplate'
System.Windows.ResourceDictionary Warning: 9 : Resource not found; ResourceKey='TwoLineLabelControlTemplate'`
