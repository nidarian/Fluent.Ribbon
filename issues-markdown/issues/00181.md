You can. I guess I won't include this in the library as I don't think it would be used frequently.

To achieve what you want you have to get "PART_RibbonTabControl" from the Ribbon, and from that one get "PART_TabsContainer" and set Visibility=Collapsed.
That should do the job.

## batzen commented on 2015-10-23T14:50:29Z

Ok, I assumed more WPF "hacking" experience. ;-)

You can achieve that without having to edit the library, but it won't work with a simple style.

You got multiple ways to go here:
- Behavior
- AttachedProperty
- Code-Behind

The easiest reusable way, without external dependencies to System.Windows.Interactivity, would be the AttachedProperty.

Here you go:

```
    using System;
    using System.Windows;
    using System.Windows.Controls;
    using System.Windows.Threading;

    public class DisableTabsContainer
    {
        public static readonly DependencyProperty IsTabsHeaderVisibleProperty = DependencyProperty.RegisterAttached("IsTabsHeaderVisible", typeof(bool), typeof(DisableTabsContainer), new PropertyMetadata(true, OnIsTabsHeaderVisibleChanged));

        public static void SetIsTabsHeaderVisible(DependencyObject element, bool value)
        {
            element.SetValue(IsTabsHeaderVisibleProperty, value);
        }

        public static bool GetIsTabsHeaderVisible(DependencyObject element)
        {
            return (bool)element.GetValue(IsTabsHeaderVisibleProperty);
        }

        private static void OnIsTabsHeaderVisibleChanged(DependencyObject d, DependencyPropertyChangedEventArgs e)
        {
            var ribbon = d as Ribbon;

            if (ribbon == null)
            {
                return;
            }

            ChangeVisibilityOfTabsHeader(ribbon, (bool)e.NewValue);
        }

        private static void ChangeVisibilityOfTabsHeader(Ribbon ribbon, bool isVisible)
        {
            if (ribbon.IsLoaded == false)
            {
                ribbon.Dispatcher.BeginInvoke(new Action(() => ChangeVisibilityOfTabsHeader(ribbon, isVisible)), DispatcherPriority.Background);
                return;
            }

            var tabControl = ribbon.Template.FindName("PART_RibbonTabControl", ribbon) as Control;

            if (tabControl == null)
            {
                return;
            }

            var tabsContainer = tabControl.Template.FindName("PART_TabsContainer", tabControl) as UIElement;

            if (tabsContainer == null)
            {
                return;
            }

            tabsContainer.Visibility = isVisible
                                           ? Visibility.Visible
                                           : Visibility.Collapsed;
        }
    }
```

Usage:

```
<Fluent:Ribbon attachedProperties:DisableTabsContainer.IsTabsHeaderVisible="False">
```

You should keep in mind that you should only add one RibbonTab to your Ribbon when you go this route, as things like scrolling with your mousewheel still changes tabs etc..
