## batzen commented on 2021-02-27T09:07:36Z

The build-script fails because you downloaded the code and didn't use git.
=> Will fix that in the future.

The target frameworks are grayed out because there is not one target framework for Fluent.Ribbon but 4 instead (net452, net462, netcoreapp3.1 and net5.0).

The package manager UI in studio might fail because Fluent.Ribbon uses CPVM (central package version management) to define global versions for all referenced nuget packages.

The only additional software you have to have installed is the .NET 5.0 SDK, but that should be installed by Visual Studio 2019, if you are using an up to date version (at least 16.8).

Could you try to run `dotnet build` instead of `build.ps1`?
