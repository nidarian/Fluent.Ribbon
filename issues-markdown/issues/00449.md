## batzen commented on 2017-07-14T13:56:41Z

ThemeManager is a static class.
Static classes can't be injected. Even if you could inject ThemeManager you would still need a reference to Fluent.Ribbon in the project using it. If you want to use a mock for unittesting you would have to write a wrapper around ThemeManager and use that in your tests.
