## batzen commented on 2015-12-21T17:48:59Z

The code forces WPF to re-apply the window style.
WPF does seem to be picky when it comes to implicitly changing the window style so I had to make WPF think that it changed.

The width is changed to force WPF to do a full re-layout of the whole window and changing it's size was the easiest way to achieve that.
