## chdft commented on 2015-07-21T17:41:19Z

It is not exactly what you (ghostriderace) wanted, but this is as close as I got to a solution:
You can use the following to display a non-interactive image of a visual:

``` xaml
    <Rectangle Width="250" Height="128">
        <Rectangle.Fill>
            <VisualBrush Stretch="Uniform" Visual="{Binding ElementName=YourContent}" />
        </Rectangle.Fill>
    </Rectangle>
```

This works perfectly fine, as long as the rectangle itself isn't part of the visual that should be shown. You can show the main content of your window, but you have to exclude the Ribbon (as that would include the backstage with your preview area). That obviously also means, that you can't use the window itself as source, because that would include the ribbon...
