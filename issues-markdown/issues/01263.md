## batzen commented on 2026-01-25T10:17:27Z

Which issues exactly do appear in your app?
One of the changes was that ControlzEx now also sets `DWMWA_USE_IMMERSIVE_DARK_MODE` depending on the current theme.
Another one is that backdrop effect support was added, could you try to set `controlzex:WindowBackdropManager.BackdropType` to `None`?
Do the issues also occur if you use a regular window instead of a RibbonWindow?

## pschimmel commented on 2026-01-30T13:01:05Z

Hi!
I had the same issue after updating to v11 with a WindowsFormsHost. Setting the attached property directly fixed the issue for me.
I added the property like this:
```
<Fluent:RibbonWindow 
  ...
   xmlns:controlzEx="urn:controlzex"
 ...
   controlzEx:WindowBackdropManager.BackdropType="None"
 ...
```
