## TruePluto commented on 2017-08-29T02:01:08Z

You had better set **Icon** and **LargeIcon** simultaneously.
**Icon** for **SizeDefinition** ="**Small**"/"**Middle**" **LargeIcon** for **SizeDefinition** ="**Large**". When you just set **Icon** but not set **LargeIcon**, you will get a blank button just with text.
