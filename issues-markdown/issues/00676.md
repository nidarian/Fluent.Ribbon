# Issue #676: Caption bar height is incorrect!

- **State:** closed
- **Author:** znakeeye
- **Created:** 2018-11-29T16:28:34Z
- **Closed:** 2019-08-07T18:04:43Z
- **Labels:** Styles
- **Original:** https://github.com/fluentribbon/Fluent.Ribbon/issues/676

In `v7` the height of the caption bar is **incorrect**. Maybe it is correct on a system with `DPI` set to 100%, but that's quite rare these days (Windows 10 usually defaults to 125% or 150%).

Refer to the `RibbonWindowStyle`:
```xml
<Setter Property="TitleBarHeight"
        Value="{DynamicResource {x:Static SystemParameters.WindowCaptionHeightKey}}" />
```

This value must be converted using the system's `DPI` setting. E.g.:

```c#
double captionBarHeight = SystemParameters.WindowCaptionHeight;

Matrix? matrix;
var source = PresentationSource.FromVisual(element);
if (source != null)
{
    matrix = source.CompositionTarget?.TransformToDevice;
}
else
{
    using (var src = new HwndSource(new HwndSourceParameters()))
    {
        matrix = src.CompositionTarget?.TransformToDevice;
    }
}

if (matrix.HasValue)
{
    captionBarHeight *= matrix.Value.M22;
}

// use captionBarHeight
```
