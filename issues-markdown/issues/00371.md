I have been using Fluent for a while now and have been able to set the color theme just fine using the following code
 `<Color x:Key="{x:Static Fluent:MetroColors.ThemeColorKey}">#1E90FF</Color>`

`<ResourceDictionary Source="FluentAlterations.xaml"/>`

Is it possible to have the value for MetroColor.ThemeColorKey set dynamically based on a property in Properties.Settings? How would one go about accomplishing this? Thank you for your time.
