## Davidos56 commented on 2017-01-05T12:28:45Z

OK I found the solution for this . Only what we can do is  add ContextMenuOpening property with handler.

<f:Ribbon ContextMenuOpening="FRibbon_ContextMenuOpening" >


and in background we have to write this function : 

 private void FRibbon_ContextMenuOpening(object sender, ContextMenuEventArgs e)
        {
            e.Handled = true;
        }

In all ribbon we deable context menu.I apologize for the problems.
