# Issue #742: Pin button not clickable when Ribbon in collapsed state

- **State:** closed
- **Author:** JasonXu-YK
- **Created:** 2019-09-12T05:52:44Z
- **Closed:** 2019-09-14T07:26:05Z
- **Labels:** Duplicate
- **Original:** https://github.com/fluentribbon/Fluent.Ribbon/issues/742

Issue:
Problem with pin button for pinning ribbon when in collapsed state.
Expected behaviour:
Pin button should be clickable, and ribbon should be pinned after clicking the pin button.
Encountered behaviour:
Pin button is not clickable. Shortcut (Ctrl + F1) still works.
Recreating issue:
Create a new project and add the ribbon with one or more menu items.
Collapse the ribbon using the collapse button or shortcut.
Click on a menu item to display the ribbon so that the collapse button changes to a pin.
Pin button is displayed, but not clickable.
Other notes:
As mentioned, shortcut (Ctrl + F1) still works.
There is no code behind for the Window except the initialisation component.

Environment
Fluent.Ribbon 6.1.0.326
Windows 10 Enterprise
.NET Framework 4.7.2
