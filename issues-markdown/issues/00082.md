## batzen commented on 2015-03-19T18:46:18Z

It's simply not needed when targeting .NET 4.5 as the classes (WindowChrome etc.) we use from there when targeting .NET 4.0 are now part of .NET 4.5.


---

## batzen commented on 2015-03-19T18:47:01Z

#if NET40
    using Microsoft.Windows.Shell;
#else
    using System.Windows.Shell;
#endif
