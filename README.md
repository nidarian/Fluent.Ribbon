# Upstream archive

Copied monthly from https://github.com/fluentribbon/Fluent.Ribbon by
`.github/workflows/archive-upstream.yml` on the develop branch.

- `issues-markdown/INDEX.md`: readable list of every issue and PR
- `issues-json/`: complete raw API data (lossless)
- `wiki/`: the project wiki
- NuGet packages and release files are in this repo's GitHub
  Releases: `archive-nuget` and `archive-releases`
